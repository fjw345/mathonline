# 全量题图工作台

双击项目根目录的 `打开全量切题工作台.cmd`，或运行：

```powershell
python -B -X utf8 tools/image_bank_workbench/app.py
```

浏览器打开 http://127.0.0.1:8767/ 。搜索来源文件，选择“看题图”查看题干和配套答案，选择“调整边框”进入已有的拖框工具。该端口与原试切工作台 8766 分开。

本批数据在 `data/image_bank/runs/20261008-full-v2/`。`manifest.json` 保存来源、坐标与图片路径；`workspaces/` 按来源分别保存可编辑标注。答案片段可以来自另一份来源文件。

图集显示本批初切快照；调整并保存后，在编辑器中导出已确认题目的 ZIP 获取最新题图。保存时保留历史修订，版本冲突会提示刷新核对。

题框确认不代表答案核对或判分配置完成。未确定答案的题目保留候选状态，原文自带的正确答案也可能仍显示在题干中。详细范围与检查记录见批次 `REPORT.md`。

重新运行转换、OCR 或切分时，必须保留原始 resource、旧批次和人工标注。当前全量结果是可复核草稿，不应直接覆盖现有正式题库。
