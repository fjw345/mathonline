# 题目 PDF 框选工具

这是一个独立的本地工具，用于把 PDF 中的题目手动框选成题目图片。它只在本目录的 `projects/` 和 `exports/` 保存工作数据，不改动 `resource/`、`olddirect/` 或任何数据库。

## 启动

在项目根目录运行：

```powershell
python -m pip install -r tools/question_cropper/requirements.txt
python tools/question_cropper/app.py
```

然后打开 <http://127.0.0.1:8765>。也可以使用 `python -m uvicorn tools.question_cropper.app:app --host 127.0.0.1 --port 8765` 启动。

## 使用

1. 点击“导入 PDF”；文件会复制到本工具的项目目录，并记录 SHA-256、页面尺寸和旋转信息。若要保存完整原路径并检查原文件是否被移动，可使用“从路径导入”。
2. 在页面上直接拖动鼠标框选会自动新建一道题；按住 `Shift` 再拖动，会把区域追加到当前题目。继续翻页并按住 `Shift` 框选，就能组成跨页题目。右侧的“＋ 新题”仍可用于先创建空题目。
3. 拖动已有框可以移动，拖动选中框右下角的圆点可以调整大小；题卡支持改题号、上下排序、标签、来源、年份和审核状态。题目不再设置难度字段。
4. 工具会自动保存，也可以点击“保存项目”。重新打开页面右上角的已保存项目即可恢复坐标和题目属性。
5. “导出…”可输入一个绝对父目录；工具会在其中创建 `<项目 ID>/`，里面包含按原 PDF 区域渲染的 PNG、`manifest.json`、`manifest.csv`、`project.json` 和 `README.md`，并下载 ZIP。重复导出会先提示，再覆盖同一个项目目录。默认父目录是本工具的 `exports/`。

导出的区域使用 PyMuPDF 直接从原 PDF 渲染，公式、选项和图表不会经过 OCR 重绘。OCR 文本只作为可选的检索辅助字段，不能替代人工复核。

## 坐标约定

`manifest.json` 中每个区域的 `bbox_pt` 使用 PyMuPDF 未旋转页面坐标：原点在页面左上角，单位是 PDF point（1/72 英寸），`page` 从 1 开始；同时保存页面宽度、高度和旋转信息。浏览器缩放只影响显示，保存和导出时会重新使用这些原始 PDF 坐标。导出目录禁止使用 `resource/`、`olddirect/`、`.git` 和工具的内部工作目录。

## 当前边界

工具按单个 PDF 项目工作，导出前需要人工检查题目边界和版权状态。路径或文件名含“月考”的项目会显示排除原因并禁止导出。它不自动拆题、不自动发布 OCR 结果，也不连接线上数据库、账号或云存储。
