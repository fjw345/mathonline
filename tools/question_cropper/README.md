# 切题工作台：5 页小规模测试

本地运行，现有 Python + PyMuPDF + Pillow 即可。首次启动准备 3 份试卷的 5 页、37 道候选题；第一轮只需检查 2019 考研数一前 10 题。初框来自 PDF 文字位置辅助和原图视觉初划，**不是通用自动切题模型的准确率测试**。

## 打开

双击本目录 `start.cmd`，保持窗口打开，在浏览器访问 <http://127.0.0.1:8766/>。

也可以在 `D:\mathonline` 执行：

```powershell
python -X utf8 tools/question_cropper/app.py
```

若 8766 被其他程序占用，可加 `--port 8767`，并打开对应地址。

## 请你做的第一轮测试（约 10–15 分钟）

1. 保持默认的“01 · 单栏与跨页”，依次检查前 10 题。核对题干、公式、四个选项、配图是否完整，是否混入下一题。
2. 至少试着调整一次框：拖角点或边缘改变大小；拖框内移动。右侧预览实时更新。也可在“精确调整与合并”中输入四边百分比，或聚焦原页后用方向键移动、Shift + 方向键调整右/下边。
3. **第 6 题跨页**：右侧有两个片段，第二片段来自原卷第 2 页的 C/D 选项。点击片段可跳转原页，检查它确实属于第 6 题。片段可上下调整顺序。
4. 完整后点击“确认边界，下一题”。确认过的题修改后会变回待检查。
5. 看到顶部“已保存”后刷新一次，确认框、备注和确认状态仍在。
6. 点击“导出已确认题目”，解压 ZIP，打开 `images/题目ID/stem.png` 检查清晰度；第 6 题应包含完整的跨页选项。
7. 在左侧“本页测试记录”记下大致用时、修改了哪几题、最不顺手的操作。完成后告诉我这些结果；不用手工抄坐标。

还有余力时，再测试“02 · 扫描件”第 1–5 题和“03 · 双栏页面”任意 3 题。扫描件第 5 题也跨页；双栏按左栏再右栏阅读。

## 其他操作

- **框选新题**：在原页拖出矩形，之后编辑题号。
- **补充区域**：选中题目后点击此按钮，可切换同卷页面并补画。区域归到同一道题。
- **点线拆题**：选中单片段题干框，在两题之间点击，分成上下两道题；之后调整题号。跨页多片段题不直接拆分，避免混乱。
- **合并**：在“精确调整与合并”选择另一题，将其片段并入当前题。含答案、解析、备注的另一题会提示先处理内容。
- **题干 / 答案 / 解析**：每个片段可以选择用途；三者分开导出。至少保留一个题干片段。
- **删除与撤销**：可删除所选片段；删除最后一个片段会删除该候选题。可撤销、重做；撤销历史限当前页面会话。
- **放大**：原页支持 50%–250% 显示；坐标以原页比例保存，不随浏览器缩放改变。

## 保存位置

所有修正独立存放于 `data/cropper_trial/`，不写入现有 SQLite 题库，不修改原始 PDF：

- `sample.json`：不可变的原始样本、文件哈希、页信息和候选框；重启不会重新生成覆盖。
- `annotations.json`：当前人工标注（题号、题型、标签、答案、区域顺序、确认状态、备注）。
- `annotations.previous.json`：上一次保存版本。
- `exports/trial-r版本.zip`：按保存版本输出的导出包。

自动保存失败时会明确显示错误；浏览器本地草稿可供恢复或下载。多个窗口出现版本冲突时拒绝覆盖。请尽量只开一个编辑窗口。原卷哈希变化时启动会拒绝套用旧坐标。

ZIP 内包含 `questions.json`、`all-annotations.json`、`trial-report.json` 和 `images/`。每题每个片段保留独立 PNG，同时按用途生成拼接图片。导出从原 PDF 渲染，约 216 DPI（超大页面最长边限制为 5000 px），不重绘公式，也不对扫描源进行“补字”。

只有已确认题目导出为图片，但全部草稿坐标仍随包备份。**边界确认不代表答案已核实，也不等于正式发布。**

## 本轮边界

用于验证修正是否顺手、题图是否完整、跨页是否正确、保存是否可靠。不自动判题，不自动推断难度或知识点，不导入正式题库，也不提供全库重切按钮。此轮“点线拆题”作用于单个已有题框；整页共享分割线、自动版面检测和任意 PDF 导入可根据实测结果再做。
