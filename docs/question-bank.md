# 题库扩充与修改

## 网页维护

本地首次注册后进入“管理 → 题库维护”。修改已有题目时保持稳定 ID；可以更换题干/答案截图、调整片段顺序、编辑题库标签和元数据、发布或下架。移除图片引用不删除原卷或其他版本的文件。不再设置难度评级。

标签用于区分题库类别。目前 222 道题统一使用“全国大学生数学竞赛·非数”，年份单独筛选，不再把年份、科目或难度当作标签。以后导入考研数学、CMC 数学类等题目时，在对应题目的 `tags` 中填写题库类别；公开筛选自动汇总可见题目的标签，没有实际题目的类别不会预先显示。来源、组别和科目仍用于后台核对原卷，不作为用户筛选条件。旧清单的 `difficulty` 字段可以读取，但导入后按 `null` 保存。

点击“新增题目”，填写英文/数字组成的稳定 ID（例如 `bjt-math-2026-q1`）、来源 ID、来源名称、题型和元数据，上传题干及答案图片后保存，默认发布，无需逐题预审。属于同一卷的题目复用来源 ID。暂未完成的题目可主动保存为草稿。选择题须另填选项 ID 和正确选项，填空题/解答题不需要补录标准答案文本。

上架、改图和修改元数据会递增题目版本。作答历史、曾做对/曾做错及点赞仍关联同一个 ID；旧作答标记“题目已更新”，旧正确结果不自动作为新版本发布题解的依据。新版本再次做对后恢复发布资格。同一版本以后做错不会失去已经取得的资格。

## 批量导入

`data/nonmath-manifest.json` 是首批显式对应关系，不以文件名实时配对。稳定 ID 对应考试、卷别和原卷题号，题干/答案图片分别按列表顺序展示。清单中的 `assets` 保存图片尺寸、原始截图路径与内容哈希；旧截图缺少页码/坐标时不虚构。

```powershell
python -X utf8 scripts/import_bank.py data/nonmath-manifest.json
```

- 相同内容再次导入不变更版本或重复建题。
- 修改清单中的题目并保留 ID，会更新未被网页手改的题目并递增版本。
- 网页改过的题目设置 `manual_revision=true`，默认受保护。确需以清单覆盖时手动使用 `--override-manual`。
- 清单没有列出的原题不会被删除。下架使用 `status=archived`，从练习池移出。
- 原始图片变化后需要建立新资产条目：重新计算哈希、更新图片 ID 和对应列表。旧资产保持不变，避免缓存或历史引用意外指向新内容。

`scripts/build_image_manifest.py` 只用于当前全国竞赛非数目录的首次清点/候选配对，默认拒绝覆盖已有清单。其规范化规则适配空格、括号、点号和“上/下”；这不是通用切题工具，也不证明内容匹配准确。

管理页“导出清单”导出题库元数据和现有图片 ID 引用，“导入清单”可将其导入同一资产库，并同样保护人工修订。迁移到另一台电脑时必须同时备份/复制资产与数据库，单独 JSON 不是完整图片题库备份。

## 用户反馈与核查

题目默认发布，原首批未人工修订的草稿自动改为已发布，不改变题目版本、答案查看权限和学习记录；手动保存的草稿与已下架题目保持原状态。旧首批清单重复导入不会恢复为草稿。默认只展示已发布题目，`LOCAL_PREVIEW_DRAFTS=true` 可选启用本地草稿预览。

登录用户在做题页点击“反馈问题”，选择“题目不完整”“答案不匹配”或“其他问题”，可补充说明。反馈不改变题目状态、作答结果或答案权限；只有管理员可查看反馈列表。

管理员进入“管理 → 题目反馈”，按待处理、已处理、无需修改或全部筛选。列表保留反馈时的题目版本，并显示当前版本，支持查看与编辑题目。修改截图或答案后填写处理说明并标记已处理；核查无误时标记无需修改。处理记录保留，避免重复处理覆盖结果。必要时可从题库维护手动下架题目。

发布仍检查题干和答案图片引用有效，不以未核查的内容冒充人工审核通过。没有可用答案的题目应保持草稿。
