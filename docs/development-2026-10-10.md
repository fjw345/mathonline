# 本地 MVP 开发记录

日期：2026-10-11。按用户最新要求，先使用全国大学生数学竞赛非数学类已拆分题目开发本地版，暂不接入远程项目。原有素材未被修改或重新切分。

## 首批题库

`devided-math/数学竞赛历年题目及解析/全国大学生数学竞赛/非数/` 中 22 个年份/卷别目录，清点结果为 222 道候选题、500 张截图：107 道填空题，115 道解答题。已有“上/下”、空格/括号和点号命名通过一次性规范化映射为有序图片清单；本次未发现无对应题号的题面/答案条目，所有 PNG 通过 Pillow 文件完整性校验。

题号能配对与图片文件可用不等于内容经过逐题核对。题面完整性、答案对应关系及使用依据均标记待复核，默认作为本地草稿预览，未对外发布。清单保存于 `data/nonmath-manifest.json`。

## 已完成

前端采用 Vue 3、TypeScript、Vite、Vue Router，后端使用 FastAPI。本地使用 SQLite 和磁盘资产副本，不需要外部服务账号。已实现注册登录/退出、昵称维护、图片题库筛选与分页、原图放大、随机练习、按筛选每日固定题、文字/图片私人作答、自检与打卡、学习历史与错题、题解和一级评论、审核、点赞与通知。

填空题和解答题提交后进入待自检，核对答案后自评整题；待自检不更新正确/错误历史、不打卡。选择题自动判分能力已经实现并以合成测试验证，但当前真实素材不含选择题。

管理页可新增题目、上传/替换/排序题干和答案图片、编辑元数据与标签、确认来源、发布或下架、导入导出 JSON、分配用户角色。稳定 ID 保持题库与个人状态的关联；修改递增版本，旧作答仍保留并提示重新核对。重复导入不重复建题，也不覆盖后台人工修订；缺失于新清单的题目不被删除。

根目录 `启动数学刷题平台.cmd` / `scripts/start_local.py` 提供一键准备与启动。首次本地注册自动获得管理员权限，无预设口令；主数据库在验收结束时没有测试账号和作答。浏览器验收另用 `data/browser-smoke.sqlite`，自动化测试使用临时数据库。

- Playwright 浏览器验证注册、每日题提交、自检打卡、题解提交与审核、题干放大及 Escape 关闭、多片段参考答案、管理页新增题目与图片上传。页面在电脑宽度和 375px 手机宽度检查，图片没有被横向拉伸。

平台名称改为“来学数学”，页面标题、导航和页脚保持一致，本地启动端口统一为 `8011`。封面插图改为带 `a`、`b` 上下限的定积分，横轴端点对应阴影区间，阴影上边界与函数曲线一致。

随机练习按账号与筛选条件保留当前题目及文字、图片、选项和题解编辑草稿，页面切换和刷新后恢复。草稿保存在当前浏览器，不自动提交或影响打卡；不同账号互不恢复对方的草稿。重新进入时读取最新题目，题面更新保留草稿并提示重新核对，下架或不再符合筛选时重新抽取可用题目；点击“换一题”更新当前题目并清空上一题的编辑状态。服务器已有更新的提交时优先使用最新提交，避免旧浏览器草稿覆盖它。

本次 TypeScript/生产构建、Prettier 与 Ruff 检查通过，18 项后端测试通过。一键启动检查通过。浏览器在独立 `data/draft-smoke-20261010.sqlite` 验证文字/图片草稿的页面返回与刷新恢复、明确换题、每日题路由切换、账号退出/切换隔离、筛选条件隔离与参数顺序、题目修改后的提示、最新服务器提交优先及下架后的替换；原有账号与学习记录不用于测试。定积分插图截图在 `output/playwright/definite-integral.png`。

## 练习页筛选与手动打开每日题

每日一题与随机练习页面新增共用筛选表单，支持题库标签、年份、题型和关键词；不提供组别、科目、来源或难度筛选，也不显示难度评级。动态预览匹配题数，零匹配时提示调整条件。标签从题库读取，当前 222 道题统一使用“全国大学生数学竞赛·非数”；管理员增改标签或导入新题库后，实际存在的标签自动出现在筛选中。

每日题页面先读取当前账号的今日状态，选择条件与查看匹配数量都不分配题目，只有点击“打开今日题目”才分配。首次打开后的题目及筛选当天固定；重进页面需要手动点击“继续今日题目”，文字/图片等编辑草稿按账号和日期恢复。已固定的条件用简短摘要展示，可展开查看。登录前选好的标签与条件在登录后保留。

随机练习修改筛选不会立即换题，点击“应用筛选”才切换范围。各组范围独立保留题目与草稿；导航再次进入恢复上次应用的条件，点击“换一题”在已应用的范围内重新抽取。选择新的筛选条件时暂时禁用换题，避免混淆未应用与当前条件。账号之间的范围、题目、每日状态及草稿互相隔离。

本地服务、启动器、开发代理、来源配置与说明统一使用 `8011`。新增原生 SVG 积分图标及 ICO、手机触屏 PNG 版本，构建和本地静态服务支持这些资产，图标更新也会触发启动器重新构建。

TypeScript/生产构建、Prettier、Ruff 检查及 23 项后端测试通过，覆盖每日状态只读、标签选题、无匹配不分配、当天筛选固定、账号隔离与跨日状态重置、已移除筛选参数兼容、题库标签迁移与人工修订保护。浏览器使用独立 SQLite 验证登录筛选恢复、手动打开/继续每日题、每日与随机草稿、随机范围切换与导航恢复、当前标签、旧筛选草稿兼容、动态新增题库标签及图标加载。375px 手机视图无横向溢出，截图位于 `output/playwright/collection-library-mobile.png` 与 `output/playwright/collection-practice-mobile.png`。

## 作答后解锁参考答案

首次作答时参考答案折叠并锁定，页面不请求答案内容。在提交作答按钮左侧增加“不会”；成功提交或点击“不会”后解锁并展开答案。“不会”保留文字、图片和选项草稿，不生成作答记录、不自动判错或打卡。提交后仍沿用原有自检流程。

答案权限按账号和稳定题目 ID 持久保存，已有作答记录也视为已解锁；题库修改版本后仍保留权限，旧作答继续显示版本提示。再次进入、刷新、随机换题以及每日题继续打开时，答案一律默认折叠；不从浏览器草稿恢复展开状态。后端答案接口与答案图片校验权限，管理员维护素材仍走管理权限。

本地 SQLite 自动增加独立权限表，保护已有数据；Supabase 对应迁移为 `202610100002_answer_access.sql`，尚未部署。题库分类迁移为 `202610110001_collection_filters.sql`，只规范未被后台人工修订的首批题目。TypeScript/生产构建、Prettier、Ruff 和启动检查通过，23 项后端测试通过。浏览器使用独立 SQLite 核验未解锁不加载答案、无效提交不解锁、“不会”保留文字/图片草稿、刷新和页面返回默认折叠、提交与正确题重做、每日题继续打开、账号/游客隔离及答案图片权限。375px 手机视图无横向溢出，“不会”与提交按钮始终左右排列。

## 管理页加载恢复（2026-10-12）

用户反馈管理页持续显示“加载中”。检查时未复现持续挂起，服务与管理接口均正常返回；原实现的请求没有超时限制，管理页还依次等待账号、审核、题库和用户接口，任何请求长期不返回都会使加载状态持续。

增加普通请求 20 秒超时、上传 60 秒超时；管理接口并行读取，加载失败显示错误和重试按钮，包括账号检查失败。题库读取共用一个 SQLite 读取事务，避免为每道题及图片反复建立连接；当前 222 道题的本机进程内读取由约 1.8 秒降至约 0.16 秒。

24 项后端测试、Ruff、TypeScript/生产构建与格式检查通过。独立浏览器测试模拟请求不返回及账号接口失败，确认超时退出加载、重试恢复 222 道题，编辑窗口、审核和用户角色页面可用。原有账号、学习记录与题库未用于写入测试；本地服务已重启以加载后端修改。

按最新要求取消题库发布前的逐题审核门槛，新增题目与未指定状态的导入默认发布，仍校验题干、答案图片引用和选择题配置。原首批未人工修订且具备答案的草稿自动发布，不改变题目版本或核对标记；人工保存的草稿、下架题目和暂无答案的素材保持原状态。旧首批清单兼容此规则，重复导入报告 222 道内容不变。页面移除“题图待核对”、逐题校验列及发布前核对复选框。

登录用户可在题目页“反馈问题”中选择题目不完整、答案不匹配或其他问题并补充说明。反馈私下提交给管理员，不解锁答案、不生成作答记录，也不自动下架题目。管理页新增“题目反馈”，显示反馈版本、当前版本、提交人及说明，可查看/编辑题目、填写处理说明并标记已处理或无需修改；已处理记录保留，并发处理只允许一次成功。社区题解和评论继续沿用原审核流程。

28 项后端测试、Ruff、TypeScript/生产构建、格式检查与启动检查通过。浏览器在独立测试数据库验证普通用户反馈、游客登录跳转、管理员队列/编辑/处理/历史、答案权限与 375px 手机和桌面布局。主库与备份比对仅 222 道题的状态改变，账号、作答、每日题、答案权限及社区记录保持一致，主库没有测试反馈。对应 Supabase 迁移已准备，尚未在远程项目执行。

## 云端读取优化（2026-10-15）

Supabase 题库列表通过 PostgREST 执行年份、题型、标签筛选和分页，精确返回总数；关键词仍保留原有字面子串语义，在筛选后的候选数据上执行。关联图片和来源按 ID 分批读取，用户状态仅在本次请求内按账号批量读取，答案权限不跨请求缓存。管理页提前批量载入答案与图片；详情、随机练习、每日题和答案图片读取复用批量读取逻辑。题图接口使用数组包含条件查找引用，避免每张图拉取全部题库。类别统计使用 30 秒实例内公共缓存，题目保存后本实例清缓存。详情图片增加延迟加载和异步解码。

34 项测试及 Ruff 通过，包含模拟 Supabase 的分页参数、标签、字面搜索、账号隔离、解锁后新请求、类别缓存过期和 222 题批处理图片顺序。12 题登录用户列表的题目与关联数据在模拟测试中为 6 次 Data API 请求（不含认证）；222 题管理页关联数据为 13 次批量请求（不含题目列表与认证）。无需新增 SQL；推送后由 Vercel 部署。未连接实际云端项目，线上延迟需要部署后测量。
