# 公共模型、个人模型与按需判题

> 文档状态（2026-11-17）：**当前维护；AI 模型配置与普通练习判题入口。**

## 使用方式

- 默认使用管理员配置的公共模型，用户无需填写密钥。
- 「我的学习 → AI 设置」可选择 OpenAI 或 DeepSeek，填写官方 API 密钥、文字模型名称及可选图片模型。保存后，该账号的判题、学情分析、考试预测及一题多练使用个人文字模型，费用由个人模型账号承担。模型名称须是账号实际可用且支持 Chat Completions 的模型；不接受自定义接口地址。
- 图片模型填写支持图片输入的模型名称，与个人文字模型共用该服务商的密钥。留空时使用管理员配置的公共图片服务；没有可用图片服务时，纯图片作答改用自检。
- 「恢复公共模型」会删除该账号保存的个人密钥和模型配置。修改个人模型需要重新输入密钥，页面只显示末四位。
- 旧版只保存了密钥的用户继续沿用管理员配置的接口与模型；可在设置页重新保存为明确的个人配置。

## 普通练习提交流程

1. 用户提交作答，服务器保存并解锁参考答案。
2. 页面先展开参考答案，再显示「是否使用 AI 判题？」及「AI 判题」「自己核对」两个选项。
3. 选择 AI 判题才发送本次作答；纯图片作答也在此时才调用视觉模型转写。完成后展示判分、得分点及说明，仍可自检修正。
4. 选择自己核对后显示正确/错误按钮。没有选择或判题失败时保持待核对，不伪造结果、不完成每日打卡；失败后可重试或转为自检。

选择题继续使用确定的选项自动判分，不调用 AI。「不会」仍直接解锁答案并加入错题，不触发 AI。刷新、重进或重做默认折叠参考答案。模拟卷交卷与变式题判分沿用各自既有流程。

## 管理员部署

在 Vercel 服务端配置以下变量并重新部署；本地则配置根目录 `.env` 并重启。真实密钥不要写入前端或提交到 Git。

```dotenv
AI_ALLOW_SERVER_KEY=on
AI_BASE_URL=你的公共模型兼容接口地址
AI_API_KEY=你的公共模型密钥
AI_MODEL=公共文字模型名称
AI_KEY_SECRET=原有的加密密钥或首次生成的加密密钥
```

`AI_ALLOW_SERVER_KEY` 现在默认开启；若旧部署显式设为 `off`，需要修改为 `on`。公共模型的调用费用由管理员的模型账号承担。`AI_KEY_SECRET` 仅用于个人配置加密，未配置不影响公共文字模型，但用户不能保存个人配置；已有用户密钥时必须保留原值，否则已有密文无法解密。

第一次配置加密密钥可运行：

```powershell
python -c "import os,base64;print(base64.urlsafe_b64encode(os.urandom(32)).decode())"
```

公共图片转写可单独设置 `AI_VISION_BASE_URL`、`AI_VISION_API_KEY`、`AI_VISION_MODEL`，模型必须支持图片输入。未设置时沿用公共文字配置；若文字模型不支持图片，须另配图片模型，否则转写请求可能失败并提示自检。`AI_BLUEPRINT_MODEL`、`AI_VARIANT_MODEL` 仍用于公共模型的蓝图和生题分工，个人文字模型覆盖这两种用途。`AI_REASONING_EFFORT` 只用于公共文字模型，不继承到个人模型或独立视觉请求。

本次无需新增数据库迁移：个人服务商、模型及密钥一起加密保存在现有 `user_ai_keys.ciphertext`，兼容旧密文。前提是此前 AI 判分、图片转写及用户密钥表等迁移已完成；未完成时按原发布说明补齐，不重跑题库导入。个人生成的变式不进入公共共享题池；切换文字模型后重新生成学情报告时不会复用另一模型的报告。

此文记录代码行为和部署步骤，不代表生产已部署或已验证真实模型连接。

## 接口排错

设置页「已配置，未验证连接」仅表示服务端配置齐全，不代表已调用模型验证。兼容接口地址通常带 `/v1`，不能直接填服务商的网站首页；程序会在地址后追加 `/chat/completions`。例如 Penguin API 应配置 `AI_BASE_URL=https://penguinapi.org/v1`，模型名称须使用该平台实际开放的模型 ID，密钥也须来自该平台。

判题失败会保留待自检，并显示 HTTP 状态或安全的错误说明（密钥无效、权限不足、接口或模型不存在、限流、响应不是 JSON、判分格式不符等）。不回显服务商原始响应、密钥或作答内容；据此修正变量后重新部署。
