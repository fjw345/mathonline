> 状态：当前维护；整理日期：2026-11-17。从根目录 `维护与开发约定.md` 拆出，按任务读取相关节。
> 此页记录需保留的约束，不证明生产迁移、导入或验收已完成；专题入口见 [文档索引](INDEX.md)。

## 业务细则

### 题库与筛选

- 公开页题干和参考答案使用文字版（Markdown + LaTeX）；原始截图保留在数据库和私有 Storage，公开媒体接口不提供原题截图，管理员维护页例外。文字中的插图按题目可见性及答案解锁权限加载。
- 公开筛选只保留题库类别标签、年份、题型和关键词。不恢复组别、来源、科目筛选或难度评级；旧 `difficulty` 只兼容读取，模型归一化为 `None`。
- 2026-11-13 起新增“知识点”公开筛选（已确认）：`problems.knowledge_points` 存编码数组，按学科限制可选范围；`difficulty` 仍不面向学生展示，只作为组卷与统计的内部元数据写库，不恢复为公开筛选或难度评级。
- 标签随已发布题目动态扩充；“只保留非数一个标签”是首批阶段要求，不适用于已扩充的考研和期末题库。
- 有效题目默认发布、无需逐题预审；用户反馈后管理员核查，必要时改图或下架。缺图或正确选项不明的材料进入待补队列，不能编造答案后发布。
- 关键词搜索包含文字题面、标题、ID 和标签；原题截图不作为公开检索来源。

### 作答、答案和学习记录

- 选择题按显式选项判分，支持单选和已配置多选，不调用模型。普通填空/解答练习提交后先展示参考答案并询问是否使用 AI 判题，只有用户选择 AI 才调用判分/图片转写；选择自己核对后显示自检对错按钮。待核对不打卡，判题失败可重试或自检。模拟卷与变式沿用各自判分流程。选择 AI 后，填空题先做归一化与数值容差算法比对，算法只在“双方都是数值且不接近”时判错，其余不匹配交模型兜底；解答题依据 `problem_answers.text` 文字详解生成得分点后逐点判分，全部得分点命中才算正确，否则记错。AI 不可用、缺少文字详解或得分点缺判时降级为待自检，不假报对错；AI 判分可被用户自检修正，AI 原始快照单独保存、不被改判覆盖。仍不执行用户输入的代码，不做表达式求值。最新流程见 [公共与个人模型](ai-model-options.md)，判分算法见 [AI 自动核对答案](ai-grading.md)。
- 纯图片作答先由视觉模型转写为文字，再走上述判分；转写失败、视觉模型未配置或识别不出文字时降级为待自检，不伪造文字。转写只读取本人 `submission` 图片，文本仅本人可见并展示在 AI 核对面板；按“用户+题目+修订号+图片顺序”缓存，重试不重复调用视觉模型。
- 登录后成功提交或点击“不会”才解锁参考答案，后端接口与图片访问都检查权限；“不会”位于提交左侧，解锁、保留草稿并加入错题栏，不伪造作答或改写已有判分、不打卡。
- 答案解锁按账号与稳定题目 ID 保存；重进、刷新、重做默认折叠。折叠是界面状态，不能代替服务端权限。
- 作答结果用常驻图标、文字及颜色共同反馈，区分自动判分、自检和待自检，不能只依赖短暂提示。提交后左侧预览已提交的文字与图片，右侧参考答案可收起；手机改为上下排列。图片支持有序多图及点击放大；编辑作答时保留内容并默认收起答案，草稿不能冒充已提交预览。
- 每人每题维护当前学习状态及曾做对/曾做错，不统计重做次数。待自评不更新本次对错、不打卡；重做正确仍保留曾做错历史。
- 错题栏是独立的复习清单：答错或点击“不会”加入；在错题栏点击“已掌握，移出错题”后隐藏，保留作答历史、答案权限及曾做错标记。做对不自动移出；移出后再次答错或点“不会”重新加入。统计显示当前待复习错题数量，不能再直接累计 `ever_incorrect`。
- 题目版本、提交修订号、社区题解版本分别处理；旧页面不能覆盖新提交，旧题目版本的正确结果不能当成当前版本发布资格。

### 持续练习与社区

- 随机练习按账号和已应用筛选恢复题目与未提交草稿；切页、刷新不能默默换题。修改筛选后需应用；下一题在已应用范围抽取，候选多于一道时避免紧邻重复。
- 草稿包括文字、已上传图片引用、选项及题解编辑内容；不同账号、范围、每日日期隔离。恢复时核对最新题目与服务器提交，不恢复答案展开状态。
- 页面渲染异常通过 `PageBoundary.vue` 提示重试并允许复制本机错误详情；不要用清空浏览器数据解决白屏，以免丢失草稿。诊断不主动附带账号、Cookie、查询参数或作答内容，不自动上传；手机浏览器剪贴板不可用时可手动复制。手机模拟验收不能记为安卓真机验收，异常防护不等于已确认用户设备的根因。
- 每日题先选范围、手动打开；已分配后同账号同日固定，重进手动继续。日期按 Asia/Shanghai；跨日重置，分配和打卡需唯一约束及并发保护。
- 打卡来自当天分配题目的有效判分或完成自评，对错均可；查看答案、点击“不会”和待自评不算完成。
- 私人作答与公开题解分开。当前题目版本曾做对的用户可主动发布题解；同版本后来做错不撤销已获得资格，自评结果如实标注。
- 题解、评论仍须审核。审核人员和管理员权限有区别；题库默认发布不等于社区免审。“喜欢”兼作收藏，不另设重复系统。
- 论坛 `/forum` 汇总审核通过且关联题目仍公开的题解，按 `created_at` 从新到旧排序，以 ID 降序稳定处理同一时间；编辑不刷新原发布时间。每页 12 篇，保留页码、摘要展开、多图预览和跳转原题定位对应题解。待审核、隐藏、关联题目下架的内容不可出现在公开论坛；不返回作者邮箱或私人作答。云端先过滤、排序和分页，再批量读取本页图片，不能全量下载题解后在浏览器分页。

### 更新信箱与邀请资料（2026-11-08 确认）

- 账号附近提供站内更新信箱，不发送邮件。管理员可发布、编辑、存草稿和隐藏公告；普通用户登录后查看。每页 12 条，按创建时间倒序；已读状态按账号和公告版本隔离，编辑后重新未读，旧版本不能覆盖新编辑。
- 每个账号生成固定邀请码，允许注册后手动绑定，包括现有用户；只能绑定一位邀请人、不能更换或绑定自己，重复提交不重复计数。云端须通过可信 Auth 用户信息确认邮箱已验证，本地不发验证邮件；不能使用用户可修改的 metadata 判断验证状态。
- 直接邀请两名已验证并成功绑定的用户后解锁夸克资料链接，后端每次校验人数，管理员不得绕过。地址及提取码通过服务端 `RESOURCE_DOWNLOAD_URL` / `RESOURCE_EXTRACTION_CODE` 配置，未达人数时不返回；不把实际分享地址写入前端或公开示例，不上传 D 盘资料包。链接一旦展示，站外转发不受本站控制。
- 依赖迁移 `supabase/migrations/20261108121156_announcements_invites.sql`，RLS 及服务端权限随迁移配置；未执行时新功能明确报待迁移。上线步骤见 [更新信箱与邀请资料](announcements-invites.md)，不重跑题库导入。

### AI 学情、考试预测与一题多练（2026-11-13 确认）

- 知识点标签由 `scripts/tag_knowledge.py` 批量写入：AI 优先、关键词兜底，只写 `knowledge_points`、`knowledge_source`、`difficulty` 三列，不递增题目版本、不改题面/答案/图片；人工标注（`manual`）默认受保护。管理页可逐题校正，校正同样不递增版本。
- 学情分析只用聚合统计（知识点正确率、错题数、模拟卷得分），不把作答原文送给模型；报告按练习数据指纹缓存，模型不可用时只返回统计并明确原因。
- 考试预测以近 6 年题型结构、知识点权重与难度为输入；组卷优先用题库，**每张卷至少一道选择题或填空题是 AI 仿题**，且必须通过独立求解校验；模型不可用但共享题池有合格 AI 仿题时仍可出卷；无可用 AI 仿题则返回 503，不生成“没有 AI 题”的卷子。AI 生题可用 `AI_VARIANT_MODEL` 单独配置更强模型（留空沿用 `AI_MODEL`），以免快速模型在难题上反复校验失败。
- 模拟卷一人一卷、交卷前不下发答案；选择题/填空题自动判分。解答题可按顺序上传最多 5 张本人作答图片，交卷后仍可查看；图片先转写，再与输入文字一起参与 AI 判分。转写或判分不可用时保留作答并转待自评，不假报对错。AI 题只存在模拟卷/变式记录里，不写回公开题库。
- 一题多练对错题生成“同思路、换数据”的变式，答案在查看前由服务端隐藏；结果计入学情分析的知识点统计。
- 线上 AI 仿题默认进入共享题池（`variant_cache`）：按「源题 ID + 题目版本 + 文字答案」哈希复用，跨用户共享题目内容但不共享作答；本地默认关闭。池满（`AI_VARIANT_POOL_SIZE`，默认 3）后复用使用次数最少的一道；模型不可用但池内有时仍可出题。题目或答案改版后旧缓存自动失效。
- 功能依赖迁移 `202611130001`–`202611130004`、`20261113120000_shared_variants.sql` 与 `20261113130000_image_transcript.sql`（知识点列、学情缓存、模拟卷、变式题、共享题池、图片作答转写）；上线步骤、校验与回滚见 [知识点、AI 学情、考试预测与一题多练](knowledge-analysis-mock-deployment.md)。文档不能作为生产迁移状态的证明；AI 题不承诺 100% 正确，见该页风险说明。

### 页面风格

- AI 生题的题干、选项、答案和解析统一使用 Markdown/LaTeX。共用渲染器位于 `frontend/src/markdown.ts`，组件为 `MarkdownContent.vue`；兼容 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 及历史反引号包裹的明确公式，普通代码仍按代码显示。新生题拒绝明显乱码、未闭合定界符和花括号，并重新生成；不能猜测丢失的分式。共享题池跳过同类损坏内容但不删除旧记录；既有卷子中结构已丢失的题目需重新生成。验证命令：`npm --prefix frontend run test:markdown`，以及 `tests/test_generated_math_format.py`、`tests/test_mock_exam.py`、`tests/test_variant_pool.py`。

沿用现有 Vue/CSS 与图标体系，措辞简短，优先题目和操作。保持“来学数学”品牌及用户指定的首页标题，不加回已删除的装饰文案和装饰右栏；参考答案的功能右栏按已确认需求保留。改长标题、题面公式或文字内嵌图时检查手机尺寸、缩放及溢出。

## 题库维护与导入

- 修改已有题目保持稳定 ID，通过版本管理更新内容；默认保护 `manual_revision=true` 的网页人工修订。只有明确需要覆盖时才使用 `--override-manual`。
- 原始截图和原卷不随意裁剪覆盖、重命名或删除。资产按内容哈希保存，新图建立新资产引用，避免改变旧记录指向。
- 构建器默认保护已有输出；运行 `--replace` 前先检查是否有人工编辑。新增年份、题型及命名例外需显式配置，不把其他试卷的规则机械套用。
- 北交期末维护 `data/bjtu-final-config.json`，生成器为 `scripts/build_bjtu_final_manifest.py`；题号大题/小题与分图片段分开解析，`二11` 不是 `二1` 的分图。
- 只有正式 `*-manifest.json` 交给导入器；`pending.json`、`inventory.json`、配置及 REPORT 不能导入。
- 文字版题面/答案由 `devided-math-text/` 生成 `data/text-bank-manifest.json`；线上回填使用 `scripts/apply_text_bank.py`，只写 `question_text` 和 `problem_answers.text`，不递增题目版本、不改图片与学习记录。不要为加文字重跑全量导入，除非是在全新库。文字说明见 [docs/text-bank.md](text-bank.md)，生产步骤与备份/验证/回滚见 [docs/production-text-migration.md](production-text-migration.md)。
- 知识点批量标注用 `scripts/tag_knowledge.py`（先 `--dry-run`，默认只补缺失），只读核对用 `scripts/verify_knowledge.py`；两者都按 `APP_MODE` 连接目标环境，不重跑题库导入。标注与核对不访问模型判分接口。
- 本地一键启动（`启动数学刷题平台.cmd` / `scripts/start_local.py`）会导入非数与北交期末四科清单（考研清单较大，按需单独导入）；缺知识点时用关键词规则补齐（离线）。重复导入不会递增版本，也不会清空已有知识点或内部难度（2026-11-13 起）。
- 清单生成与离线校验不访问数据库。`scripts/import_bank.py` 会读取根目录 `.env`，按 `APP_MODE` 上传图片及写库，执行前确认目标环境，不能把它当只读验证命令。
- 历史盘点为非数与考研 1,316 题、北交期末 552 题（另 1 题待核对），合计 1,868 个可导入条目。当前数量须重新核对清单/报告，线上数量与导入结果须单独核验。
- 导入数据没有结构变化时不要求重跑旧 SQL 或部署。详细操作参考 `docs/question-bank.md` 和各批次 `REPORT.md`。

## 权限、部署与性能边界

- 不读取或输出 `.env` 的密钥值，不提交数据库、私人上传、Cookie 或令牌。前端禁止放 service role 凭证。
- 默认使用管理员配置的公共 AI（`AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL`，`AI_ALLOW_SERVER_KEY` 默认 on，旧部署显式 off 时须修改）。用户可在「我的学习 → AI 设置」选 OpenAI / DeepSeek 官方端点及个人文字/图片模型，优先使用个人配置，也可删除后恢复公共模型；不接受任意用户接口 URL。个人配置连同密钥由 `AI_KEY_SECRET` 做 AES-GCM 加密后存现有 `user_ai_keys.ciphertext`，兼容旧密文；接口只返回安全摘要和密钥末四位，日志与错误不回显密钥。公共视觉密钥不得发送到个人端点；个人变式不复用或写入公共题池，切换文字模型后不复用另一模型的学情报告。公共/个人模型切换复用原表、不新增迁移；原 AI 判分依赖 `supabase/migrations/20261110000000_ai_grading.sql`、用户密钥依赖 `20261113140000_user_ai_keys.sql`、图片转写依赖 `20261113130000_image_transcript.sql`，未执行时明确降级或提示待更新，不假报成功。部署细节见 [公共与个人模型](ai-model-options.md)。
- 本地首次账号可初始化管理员；云端首个注册账号不自动获得管理员，维护角色用 `scripts/manage_user.py` 或受控后台流程。
- 业务表使用 RLS，但服务端凭证绕过 RLS；身份、归属、答案解锁及管理员检查必须在后端保留。私人状态不可跨账号缓存。
- 保留 `vercel.json` 的函数包排除和 `/api/v1/*` 重写，不把原卷、题图、本地数据库和前端依赖带入函数包。
- 线上持久数据在 Supabase，不使用 Vercel 临时文件系统保存账号、作答或图片。代码回滚不会回滚数据库。
- 错题清单依赖迁移 `supabase/migrations/202610230001_mistake_notebook.sql`，回填历史答错与“不会”记录；本地通过建表脚本兼容更新且重启不恢复已掌握条目。云端迁移未执行时保持读取兼容，移出操作明确提示待更新，不能假报成功。
- 2026-11-13 功能依赖迁移 `supabase/migrations/202611130001_knowledge_points.sql`、`202611130002_learning_analysis.sql`、`202611130003_mock_exams.sql`、`202611130004_practice_variants.sql`、`20261113120000_shared_variants.sql`、`20261113130000_image_transcript.sql`、`20261113140000_user_ai_keys.sql`，均为纯新增；未执行时知识点筛选为空、学情分析只显示统计、模拟卷与变式返回 503（共享题池未执行时自动退回逐次生成）、图片作答转写降级为待自检、用户密钥保存返回 503，不假报成功。线上发布使用 `supabase/release/` 的 preflight/upgrade/postcheck 三份脚本，操作步骤见 [2026-11-13 线上发布手册](release-2026-11-13-ops.md)；整段脚本由 `scripts/build_release_sql.py` 从迁移生成，改迁移后必须重新生成并跑 `tests/test_release_sql.py`。
- `APP_ORIGIN`、认证回调、邮箱和部署环境对应实际网站；配置变更需重新部署。平台限制和配置操作发生变化时查官方资料，不把历史限制数值当作永久常量。
- 保留分页、按请求批量读取、公开目录 30 秒缓存和文字渲染按需加载；性能修复先分清数据接口、认证、冷启动与公式渲染耗时。
- 公开题目接口不再批量签发原题截图 URL；文字内嵌图按请求、题目可见性和答案解锁鉴权。历史上已签发的原图链接最长 300 秒后失效，不能承诺立即撤销。
- 用户图片仍经 API 中转，不能承诺本地 5 MB 上限在线上一定可用；现有建议约 3 MB 以下。直传授权/确认、自动缩略图、孤立资产清理、完整备份演练未交付。

## 验证与常用命令

先选择与变更相关的检查，业务或共用访问层变更再扩大回归。文档整理不需要导入数据库或启动生产服务。

```powershell
# PowerShell，仓库根目录；仅当前进程环境，避免误连根目录 .env 的云端配置。
$env:APP_MODE = 'local'
$env:LOCAL_DATABASE = 'tmp/agent-tests.sqlite'
python -X utf8 -m pytest tests --basetemp tmp/agent-pytest

# 不初始化应用或数据库的期末清单离线校验。
python -X utf8 -m unittest discover -s tests -p test_bjtu_final_manifest.py

# 判分引擎算法用例：单独指定隔离临时库（导入会初始化其本地表结构），不配置 AI_*、不调用模型。
$env:LOCAL_DATABASE = 'tmp/agent-grading.sqlite'
python -X utf8 -c "from backend.grading import algorithmic_verdict as v; assert v('0.5','1/2') == 'correct'; assert v('2','3') == 'incorrect'; assert v('x=2','2') is None; print('grading algorithm ok')"

# 前端类型检查和生产构建；检查格式不自动重排文件。
npm --prefix frontend run build
npm --prefix frontend run format:check

# 知识点标注（先干跑；确认 APP_MODE 后再写库）与只读核对。
python -X utf8 scripts/tag_knowledge.py --dry-run --limit 20
python -X utf8 scripts/verify_knowledge.py

# 改过迁移后重新生成发布 SQL，并核对生成结果与迁移一致。
python -X utf8 scripts/build_release_sql.py
python -X utf8 scripts/build_release_sql.py --check
```

`--basetemp` 使用专门测试目录，pytest 会清理它，不能指向存放用户资料的目录。测试进程导入应用可能初始化配置指定的本地数据库，必须使用隔离路径；不要拿真实账号和学习记录做测试。首次安装依赖按锁文件与部署文档执行；不要为了纯文档变更更新依赖锁。

本地启动可用根目录 `启动数学刷题平台.cmd` 或 `python -X utf8 scripts/start_local.py`。启动器及其 `--check` 都可能构建前端并导入首批非数题库，不是无副作用探测；只在明确的本地数据环境运行。

涉及交互时至少核对：登录/退出、筛选、每日手动打开、随机下一题及草稿恢复、提交/不会/自评、答案折叠与越权、多图预览、管理页加载和移动布局。涉及导入时核对稳定 ID、图片哈希与顺序、完整覆盖、待补排除、重复生成及人工修订保护。

结束时说明修改范围、实际验证及未核验事项；未经本轮执行或可靠记录支持，不声称“已导入”“已上线”“已推送”或“全部测试通过”。

## AI 判分事务与后续范围

- 判分用 `record_ai_grading` 在同一事务内保存学习状态、来源、快照和每日打卡，沿用作答修订号与锁；不得在 RPC 后整行 upsert 覆盖并发修改。本地也须同事务保存。依赖 `202611160001_atomic_ai_grading.sql`，见 [合并修复说明](ai-merge-fixes.md)。
