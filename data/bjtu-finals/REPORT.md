## 后续导入

确认目标 .env 后执行以下命令（会写库并上传图片；本次未执行）：

```powershell
python -X utf8 scripts/import_bank.py data/bjtu-finals/calculus1-manifest.json
python -X utf8 scripts/import_bank.py data/bjtu-finals/calculus2-manifest.json
python -X utf8 scripts/import_bank.py data/bjtu-finals/probability-manifest.json
python -X utf8 scripts/import_bank.py data/bjtu-finals/linear-algebra-manifest.json
```

导入器自动读取根目录 .env，相同内容幂等跳过，管理员人工修改默认受保护。无须重跑旧 SQL 或修改表结构。

## 扩充与修改

维护 ../bjtu-final-config.json 的逐卷题型、正确选项与映射例外，再运行：

```powershell
python -X utf8 scripts/build_bjtu_final_manifest.py --replace
```

默认拒绝覆盖输出。使用 --replace 前请保存对生成清单的人工修改。扩充年份或课程时同步补充配置，未知年份会停止构建，不会套用其他试卷的题型。
