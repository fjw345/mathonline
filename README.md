# 来学数学 · 在线刷题平台

基于 Vue 3 + TypeScript + FastAPI 的本地 MVP。首批使用全国大学生数学竞赛非数学类已拆分截图：22 个卷别，222 道题（107 道填空题、115 道解答题），500 张图片。题目默认可用；用户发现题目不完整或答案不匹配时可反馈，由管理员核查处理。目前仅在本地运行。

## 启动

双击根目录 **启动数学刷题平台.cmd**，然后访问 **http://127.0.0.1:8011/**。

需要 Python 3.10+、Node.js 20.19+ 和 npm。首次启动自动安装缺少的 Python 依赖、安装前端依赖、构建页面并导入清单；以后启动会保护后台人工修改和已有账号、作答。

也可以手动运行：

```powershell
python -m pip install -r requirements.txt
cd frontend
npm.cmd ci
npm.cmd run build
cd ..
python -X utf8 scripts/import_bank.py data/nonmath-manifest.json
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8011
```

本地首次注册的账号自动获得管理员权限，其余账号为普通用户。没有预设密码。本地邮箱不验证、不发送重置邮件；Supabase 模式的认证对接另见部署说明。

## 已实现功能

- 图片题库、标签/年份/题型筛选、关键词搜索、分页、图片原图放大；不提供组别、来源、科目和难度筛选，不设置难度评级。
- 随机练习、每日固定题、提交文字或图片作答、填空题与解答题自检、每日打卡。
- 参考答案在成功提交作答或点击提交按钮左侧的“不会”后解锁。“不会”保留草稿，不自动判错或打卡；已解锁题目再次进入或重做时仍可查看，答案默认折叠。接口与答案图片也按账号校验查看权限。
- 每日一题和随机练习均可按标签、年份、题型和关键词筛选。每日一题先选择范围，再点击“打开今日题目”；打开后当天固定，进入页面不会自动分配。当前题库标签仅有“全国大学生数学竞赛·非数”，以后导入其他题库并填写相应标签后，筛选选项自动增加。
- 随机练习在当前浏览器按账号和筛选条件保留题目、文字/图片作答草稿与已选选项，切换页面或刷新后恢复。应用新的筛选范围时恢复该范围的上次题目，首次使用则抽取一题；点击“换一题”在当前范围内重新抽题。草稿不会自动提交、判题或打卡。
- 每日题草稿按账号和日期保留，重进后点击“继续今日题目”即可恢复。网页提供 SVG/ICO 标签页图标及手机触屏图标。
- 选择题按钮与自动判分能力；当前素材没有选择题，不补造选择题。
- 最近作答、结果依据、历史错题、喜欢的内容、个人学习统计；不保存重做次数。
- 曾做对当前版本后提交题解，题解图片、审核、一级评论、点赞与站内消息。
- 管理员新增题目、上传/替换/排序图片、修改标签与答案、草稿/发布/下架、JSON 导入导出、角色分配。
- 题目默认发布，无需逐题预审。做题页“反馈问题”支持题目不完整、答案不匹配及其他问题；管理员在“题目反馈”中编辑对应题目、记录处理说明并标记已处理或无需修改。
- 稳定题目 ID、更新版本检查、幂等导入和人工修订保护；历史记录随版本变化提示重新核对。

题库维护与扩充见 [docs/question-bank.md](docs/question-bank.md)。本地数据库是 `data/mathonline.sqlite`；图片副本位于 `data/assets/`、私人上传在 `data/uploads/`。原始 `devided-math` 和 `resource` 不被修改。

```powershell
python -X utf8 scripts/start_local.py --check
```
