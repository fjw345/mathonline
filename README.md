# 来学数学

**在线练习：[www.mathonline.top](https://www.mathonline.top/)**

来学数学提供考研数学与数学竞赛真题练习。题目和参考答案以图片展示，支持按类别选题、随机练习、每日一题和学习记录。

## 第一次使用

1. 打开网站，可以先浏览题库。
2. 点击注册，填写邮箱、密码和昵称。如果提示验证邮箱，先到邮箱完成验证，再返回登录。
3. 在题库选择标签、年份或题型，打开想练习的题目；也可以进入随机练习或每日一题。
4. 输入文字或上传作答图片，点击“提交答案”。选择题选择选项后提交；填空题和解答题提交后对照参考答案自检。

忘记密码时，在登录页点击“忘记密码”，按邮件提示重置。

在首页使用“标签”区分考研与数竞题源，再按年份、题型或关键词缩小范围。没有结果时，可以清除部分条件后重试。点击题图可放大查看。

## 三种练习方式

### 从题库选题

按筛选结果浏览题目，打开指定题目作答，适合按年份、题型或题库集中练习。

### 随机练习

先选择范围并应用筛选，再开始练习。点击“换一题”会在该范围内重新抽题。

切换页面或刷新后，同一浏览器会按账号和筛选范围恢复上次的题目及未提交草稿，包括文字、已上传图片和已选选项。切换设备或清除浏览器数据后，本地草稿不会同步恢复，重要内容请及时提交。

### 每日一题

先选择想练习的范围，再点击“打开今日题目”。打开后当天题目固定，重新进入时点击“继续今日题目”；修改筛选条件不会替换当天已打开的题目。

选择题提交后记录结果；填空题和解答题完成自评后记录结果。完成当天分配题目的判分或自评即可打卡，答错也可以完成。

## 作答与查看答案

- **提交答案**：成功提交后解锁参考答案。选择题自动判分；填空题和解答题请对照答案，自评正确或错误。
- **不会**：点击提交按钮左侧的“不会”也能解锁答案，保留草稿，不自动判错或打卡。
- **重做**：已解锁的答案仍可查看，但重新进入或重做时默认折叠，可手动展开。

登录后才能提交作答或通过“不会”解锁答案。答案解锁后无需反复提交来查看。

上传作答图片时，建议使用清晰、裁剪后的图片，云端单张尽量控制在 **3 MB 以下**。上传失败时可先压缩图片再重试。

## 查看记录与交流

在“我的学习”查看最近作答、历史错题、学习统计及喜欢的内容。已提交的记录保存在账号下，未提交草稿保存在当前浏览器中。

曾做对当前版本的题目后，可以主动发布题解；私人作答不会自动公开。题解和评论审核通过后对其他用户展示，互动消息可在站内查看。

## 发现题目有问题

在做题页点击“反馈问题”，选择题目不完整、答案不匹配或其他问题，并说明具体位置。管理员核查后会修改题目或记录处理说明。

题目修订后，历史作答可能提示版本变化，请重新核对题目和答案。

## 常见问题

**为什么看不到答案？**
请先登录，再成功提交作答或点击“不会”。已解锁的答案可能处于折叠状态，手动展开即可。

**为什么每日一题还没打卡？**
打开题目或点击“不会”不会打卡。请完成选择题提交，或完成填空题、解答题的自评。

**为什么随机练习又回到了上次的题？**
这是题目与草稿恢复功能。想做新题时，点击“换一题”。

**为什么没有“管理”入口？**
普通账号没有管理权限。云端首个注册账号也不会自动成为管理员，由项目维护者配置角色。

## 本地使用与项目维护

需要在本地运行时，可双击根目录的 `启动数学刷题平台.cmd`，启动后访问 http://127.0.0.1:8011/。首次启动需要安装依赖，请按终端提示操作。本地与线上账号、题库及作答记录相互独立。
