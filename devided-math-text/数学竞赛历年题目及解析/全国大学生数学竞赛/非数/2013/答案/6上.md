解. 作变换 $\begin{cases} x = (u - v) / \sqrt{2} \\ y = (u + v) / \sqrt{2}, \end{cases}$

曲线 $C$ 变为 $uov$ 平面上的 $\Gamma: \frac{3}{2} u^2 + \frac{1}{2} v^2 = r^2$, 也是取正向 (2分)

且有 $x^2 + y^2 = u^2 + v^2$, $ydx - xdy = vdu - udv$,

$I_a(r) = \int_{\Gamma} \frac{vdu - udv}{(u^2 + v^2)^a}$. (2分)

作变换 $\begin{cases} u = \sqrt{\frac{2}{3}} r \cos \theta \\ v = \sqrt{2} r \sin \theta \end{cases}$, 则有 $vdu - udv = -\frac{2}{\sqrt{3}} r^2 d\theta$

$I_a(r) = -\frac{2}{\sqrt{3}} r^2 (-1a) \int_0^{2\pi} \frac{d\theta}{(2\cos^2\theta / 3 + 2\sin^2\theta)^a} = -\frac{2}{\sqrt{3}} r^{-2a}(J_a)$,

其中 $J_a = \int_0^{2\pi} \frac{d\theta}{(2\cos^2\theta / 3 + 2\sin^2\theta)^a}$, $0 < J_a < +\infty$. (3分)

因此当 $a > 1$ 和 $a < 1$, 所求极限分别为 0 和 $-\infty$. (2分)
