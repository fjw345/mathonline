$$
\lim _ {n \to \infty} \frac {1}{n} \cdot \left(l n \frac {c _ {2}}{c _ {1}} + \dots + l n \frac {c _ {n + 1}}{c _ {n}}\right) = l n \frac {1}{a _ {1}},
$$

$$
{ } ^ { n } \sqrt { c _ { n } } = e ^ { \frac { l n c _ { n } } { n } } = e ^ { \frac { l n c _ { 1 } } { n } + \frac { 1 } { n } \left( l n \frac { c _ { 2 } } { c _ { 1 } } + \cdots + l n \frac { c _ { n + 1 } } { c _ { n } } \right) } \rightarrow e ^ { l n \frac { 1 } { a _ { 1 } } } = \frac { 1 } { a _ { 1 } . }
$$

从而， $\lim_{n\to \infty}\frac{1}{\sqrt[n]{c_n}} = a_1$ ，即 $f(x)$ 的最小正根.
