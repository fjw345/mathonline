解:原式 $= \lim_{x\to 0}\exp \{\frac{e}{x}\ln (\frac{e^x + e^{2x} + \cdots + e^{nx}}{n})\}$ $= \exp \{\lim_{x\to 0}\frac{e(\ln(e^x + e^{2x} + \cdots + e^{nx}) - \ln n)}{x}\} \quad$ (2分)

其中大括号内的极限是 $\frac{0}{0}$ 型未定式，由L'Hospital法则，有

$\lim_{x\to 0}\frac{e(\ln(e^x + e^{2x} + \cdots + e^{nx}) - \ln n)}{x} = \lim_{x\to 0}\frac{e(e^x + 2e^x + \cdots + ne^{nx})}{e^x + e^{2x} + \cdots + e^{nx}}$

$= \frac{e(1 + 2 + \cdots + n)}{n} = (\frac{n + 1}{2})e$

于是 原式 $= e^{(\frac{n + 1}{2})e}$ . ……(5分)
