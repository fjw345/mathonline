- 证.由马克劳林公式，得
- $f(x) = f(0) + \frac{1}{2!} f''(\mathbf{0})x^2 + \frac{1}{3!} f'''(\eta)x^3, \quad \eta$介于 0 与$x$之间， $x \in [-1, 1] \cdots 3$分
- 在上式中分别取 $x = 1$ 和 $x = -1$，得
- $1 = f(1) = f(0) + \frac{1}{2!} f''(\mathbf{0}) + \frac{1}{3!} f'''(\eta_1), \quad 0 < \eta_1 < 1. \quad \cdots\cdots5$分
- $0 = f(-1) = f(0) + \frac{1}{2!} f''(0) - \frac{1}{3!} f'''(\eta_2), \quad -1 < \eta_2 < 0. \quad \cdots\cdots7$分
- 两式相减，得
- $f'''(\eta_1) + f'''(\eta_2) = 6. \quad \cdots\cdots10$分
- 由于 $f'''(x)$ 在闭区间 $[-1, 1]$ 上连续，因此 $f'''(x)$ 在闭区间 $[\eta_2, \eta_1]$ 上有最大值 $M$ 最小值 $m$，从而
- $m \leq \frac{1}{2}(f'''(\eta_1) + f'''(\eta_2)) \leq M \quad \cdots\cdots13$分
- 再由连续函数的介值定理，至少存在一点 $x_0 \in [\eta_2, \eta_1] \subset (-1, 1)$，使得
- $f'''(x_0) = \frac{1}{2}(f'''(\eta_1) + f'''(\eta_2)) = 3. \quad \cdots\cdots15$分
