解法1. 设 $u = y^2$, 则原方程化为 $\frac{\mathrm{d}u}{\mathrm{d}x} = \frac{2u}{x(1 + x)} - \frac{2x^2}{x + 1}$. (6分)这线性方程的通解为即
$\left(\frac{1 + x}{x}\right)^2 u + (1 + x)^2 = C.$
(14分)
解法2. 原方程可化为
$x \mathrm{~d}x + y \mathrm{~d}y + y \frac{x \mathrm{~d}y - y \mathrm{~d}x}{x^2} = 0,$
即,
$\frac{1}{2} \mathrm{~d}(x^2 + y^2) + y \mathrm{~d}\left(\frac{y}{x}\right) = 0.$
(6分)
两边同时除以 $\sqrt{x^2 + y^2}$, 得
$\frac{1}{2} \cdot \frac{\mathrm{d}(x^2 + y^2)}{\sqrt{x^2 + y^2}} + \frac{1}{\sqrt{1 + (\frac{y}{x})^2}} \cdot \frac{y}{x} \cdot \mathrm{d}\left(\frac{y}{x}\right) = 0,$
即,
$\mathrm{d}(\sqrt{x^2 + y^2}) + \mathrm{d}\left(\sqrt{1 + (\frac{y}{x})^2}\right) = 0.$
故,
$\sqrt{x^2 + y^2} + \frac{\sqrt{x^2 + y^2}}{x} = C,$
即,
$(1 + x) \sqrt{x^2 + y^2} = Cx.$
(14分)
