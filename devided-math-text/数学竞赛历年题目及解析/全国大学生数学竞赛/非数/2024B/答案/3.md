解答. $f(x) = \frac{1}{4}\left(\frac{1}{x - 1} -\frac{1}{x + 3}\right) = \frac{1}{4}\left(\frac{1}{1 + x - 2} -\frac{1}{5}\cdot \frac{1}{1 + \frac{x - 2}{5}}\right).\qquad \dots \dots (4$ 分）又$\frac{1}{1 + x - 2} = \sum_{n = 0}^{\infty}(-1)^{n}(x - 2)^{n},\quad |x - 2| < 1,$ $\frac{1}{1 + \frac{x - 2}{5}} = \sum_{n = 0}^{\infty}(-1)^{n}(\frac{x - 2}{5})^{n},\quad |\frac{x - 2}{5}| < 1.$ 于是得到 $f(x)$ 在 $x = 2$ 处的Taylor展式$f(x) = \frac{1}{4}\sum_{n = 0}^{\infty}(-1)^{n}(1 - \frac{1}{5^{n + 1}})(x - 2)^{n},\quad |x - 2| < 1.$ (10分）当 $x = 1$ 时，级数变为 $\frac{1}{4}\sum_{n = 0}^{\infty}(1 - \frac{1}{5^{n + 1}})$ ，它的通项不趋于零，发散.当 $x = 3$ 时，级数变为 $\frac{1}{4}\sum_{n = 0}^{\infty}(-1)^{n}(1 - \frac{1}{5^{n + 1}})$ ，它的通项不趋于零，发散.所以该幂级数的收敛域为(1,3).
