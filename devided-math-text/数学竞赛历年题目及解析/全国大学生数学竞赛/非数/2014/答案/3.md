证明:对任意 $x \in [0,1]$，有 $|f'(x) \leq 2A + \frac{B}{2}$.

[参考解答与评分标准] 由泰勒公式，有

$$
f (0) = f ^ {\prime} (x) + f ^ {\prime \prime} (x) (0 - x) + \frac {1}{2} f ^ {\prime \prime} (\xi) (0 - x) ^ {2}, \xi \in (0, x),
$$

$f (1) = f (x) + f ^ {\prime} (x) (1 - x) - \frac {1}{2} f ^ {\prime \prime} (\eta) (1 - x ^ {2}) ^ {2}, \eta \in (x, 1),\tag{5$分$}$

上述两式相减，得到 $f(0) - f(1) = -f'(x) - \frac{1}{2}f''(\eta)(1 - x)^2 +\frac{1}{2}f''(\xi)x^2$ ，于是

${ } ^ { \prime \prime } ( x ) = f ( 1 ) - f ( 0 ) - \frac { 1 } { 2 } { } ^ { \prime \prime } ( \eta ) ( 1 ) - x ^ { 2 } + \frac { 1 } { 2 } { } ^ { \prime \prime } ( \xi ) x ^ { 2 } .\tag{8$分$}$

由条件 $|f(x)|\leqslant A$ ， $|f''(x)|\leqslant B$ ，得到

$$
\left| f ^ {\prime} (x) \right| \leq 2 A + \frac {B}{2} \left((1 - x) ^ {2} + x ^ {2}\right).\tag{...... (11分}
$$

因 $x^{2} + (1 - x)^{2} = 2x^{2} - 2x + 1$ 在[0,1]的最大值为1，故

$| f ^ {\prime} (x) | \leq 2 A + \frac {B}{2}.\tag{...... (14$分$}$
