[参考解答] 由 $\lim_{x\to 0}\left(1 + x + \frac{f(x)}{x}\right)^{\frac{1}{x}} = e^3$ 知 $\lim_{x\to 0}\frac{1}{x}\ln (1 + x + \frac{f(x)}{x}) = 3,$ 于是有 $\frac{1}{x}\ln (1 + x + \frac{f(x)}{x}) = 3 + \alpha ,$ 其中 $\alpha \rightarrow 0(x\rightarrow 0)$ ，即有 $\frac{f(x)}{x^2} = \frac{e^{3x + \alpha.x} - 1}{x} -1$ ，从而$\lim_{x\to 0}\frac{f(x)}{x^2} = \lim_{x\to 0}\frac{e^{3x + \alpha.x} - 1}{x} -1 = \lim_{x\to 0}\frac{3x + \alpha.x}{x} -1 = 2.$
