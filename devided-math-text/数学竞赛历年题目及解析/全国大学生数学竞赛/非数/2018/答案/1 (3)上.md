解 1: $\int \frac{\ln(x + \sqrt{1 + x^2})}{(1 + x^2)^{3/2}} dx = \int \frac{\ln(\tan t + \sec t)}{\sec t} dt = \int \ln(\tan t + \sec t) d\sin t$
$= \int \ln(\tan t + \sec t) d\sin t = \sin t \ln(\tan t + \sec t) - \int \sin t d\ln(\tan t + \sec t)$
$= \sin t \ln(\tan t + \sec t) - \int \sin t \frac{1}{\tan t + \sec t} (\sec^2 t + \tan t \sec t) dt$
$= \sin t \ln(\tan t + \sec t) - \int \frac{\sin t}{\cos t} dt$
$= \sin t \ln(\tan t + \sec t) + \ln |\cos t| + C = \frac{x}{\sqrt{1 + x^2}} \ln(x + \sqrt{1 + x^2}) - \frac{1}{2} \ln(1 + x^2) + C.$
解 2: $\int \frac{\ln(x + \sqrt{1 + x^2})}{(1 + x^2)^{3/2}} dx = \int \ln(x + \sqrt{1 + x^2}) d\frac{x}{\sqrt{1 + x^2}}$
$= \frac{x}{\sqrt{1 + x^2}} \ln(x + \sqrt{1 + x^2}) - \int \frac{x}{\sqrt{1 + x^2}} \frac{1}{x + \sqrt{1 + x^2}} \left(1 + \frac{x}{\sqrt{1 + x^2}}\right) dx$
