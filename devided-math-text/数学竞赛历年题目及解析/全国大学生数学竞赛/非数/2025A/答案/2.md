解答. 易知 $f(0) = 0$，所以 $\lim_{x \to 0} \frac{f(x)}{x} = \lim_{x \to 0} \frac{f(x) - f(0)}{x - 0} = f'(0)$.

记 $a = f'(0), b = \int_0^1 f(x) \, \mathrm{d}x$，则

$f(x) = x^3 + ax^2 - bx. \quad (1)$

由此得 $a = \lim_{x \to 0} \frac{f(x)}{x} = -b. \quad (6$分)

再对式子(1)的两边在[0,1]上作定积分，得

$b = \int_0^1 x^3 \, \mathrm{d}x + a \int_0^1 x^2 \, \mathrm{d}x - b \int_0^1 x \, \mathrm{d}x$

$= \frac{1}{4} + \frac{1}{3} a - \frac{1}{2} b. \quad (10$分)

与 $a = -b$ 联立解得 $a = -\frac{3}{22}, b = \frac{3}{22}$. 所以

$f(x) = x^3 - \frac{3}{22} x^2 - \frac{3}{22} x, -\infty < x < +\infty. \quad (14$分)
