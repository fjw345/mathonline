$\cos \alpha \rightarrow \cos \theta_{t} = \frac{g(t)}{t}, \quad \frac{1}{\Delta t} \int_{t}^{t+\Delta t} f(r^{2}) r^{2} dr \rightarrow t^{2} f(t^{2}).$

故 $F(t)$ 的右导数为

$2\pi \left(1 - \frac{g(t)}{t}\right) t^{2} f(t^{2}) = \pi \left(2t + 1 - \sqrt{1 + 4t^{2}}\right) tf(t^{2}).$ …… (4 分)

当 $\Delta t < 0$，考虑 $F(t) - F(t + \Delta t)$ 可以得到同样的左导数。因此

$F'(t) = \pi \left(2t + 1 - \sqrt{1 + 4t^{2}}\right) tf(t^{2})$ …… (2 分)

解法 2.. 令 $\begin{cases} x = r \cos \theta \\ y = r \sin \theta, \\ z = z \end{cases}$

则 $\Omega: \begin{cases} 0 \leq \theta \leq 2\pi \\ 0 \leq r \leq a \\ r^{2} \leq z \leq \sqrt{t^{2} - r^{2}} \end{cases}$，其中 $a$ 满足 $a^{2} + a^{4} = t^{2}$，$a = \frac{\sqrt{1 + 4t^{2}} - 1}{2}$ …… (2 分)

故有

$F(t) = \int_{0}^{2\pi} d\theta \int_{0}^{a} r dr \int_{r^{2}}^{r'} f(r^{2} + z^{2}) dz = 2\pi \int_{0}^{a} r \left( \int_{r^{2}}^{r'} f(r^{2} + z^{2}) dz \right) dr$ …… (2 分)

从而有

$F'(t) = 2\pi \left( a \int_{a^{2}}^{a'} f(a^{2} + z^{2}) dz \frac{da}{dt} + \int_{0}^{a} r f(r^{2} + t^{2} - r^{2}) \frac{t}{\sqrt{t^{2} - r^{2}}} dr \right)$ …… (4 分)

注意到 $\sqrt{t^{2} - a^{2}} = a^{2}$，第一个积分为 0，我们得到

$F'(t) = 2\pi f(t^{2}) t \int_{0}^{a} r \frac{1}{\sqrt{t^{2} - r^{2}}} dr = -\pi tf(t^{2}) \int_{0}^{a} \frac{d(t^{2} - r^{2})}{\sqrt{t^{2} - r^{2}}},$

所以 $F'(t) = 2\pi tf(t^{2}) (t - a^{2}) = \pi tf(t^{2}) (2t + 1 - \sqrt{1 + 4t^{2}})$ …… (4 分)
