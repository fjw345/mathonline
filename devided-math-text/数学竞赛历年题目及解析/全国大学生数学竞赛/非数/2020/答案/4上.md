【解】(1) $\frac{\partial z}{\partial x} = f\left(\frac{y}{x}\right) - \frac{y}{x}f'\left(\frac{y}{x}\right) + 2\varphi'\left(\frac{x}{y}\right), \quad \frac{\partial^2z}{\partial x\partial y} = -\frac{y}{x^2}f''\left(\frac{y}{x}\right) - \frac{2x}{y^2}\varphi''\left(\frac{x}{y}\right).$

(2) $\left.\frac{\partial^2z}{\partial x\partial y}\right|_{x=a} = -\frac{y}{a^2}f''\left(\frac{y}{a}\right) - \frac{2a}{y^2}\varphi''\left(\frac{a}{y}\right) = -by^2.$

因为 $f = \varphi$，所以 $\frac{y}{a^2}f''\left(\frac{y}{a}\right) + \frac{2a}{y^2}f''\left(\frac{a}{y}\right) = by^2.$

令 $y = au$，则 $\frac{u}{a}f''(u) + \frac{2}{au^2}f''\left(\frac{1}{u}\right) = a^2bu^2$，即 $u^3f''(u) + 2f''\left(\frac{1}{u}\right) = a^3bu^4.$

上式中以 $\frac{1}{u}$ 换 $u$ 得 $2f''\left(\frac{1}{u}\right) + 4u^3f''(u) = 2a^3b\frac{1}{u}.$
