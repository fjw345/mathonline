解:由于 $\frac{1}{n + 1}\sum_{i = 1}^{n}\sin \frac{i}{n}\pi \leq \sum_{i = 1}^{n}\frac{\sin\frac{i}{n}\pi}{n + \frac{i}{n}}\leq \frac{1}{n}\sum_{i = 1}^{n}\sin \frac{i}{n}\pi$ ，而$\lim_{n\to \infty}\frac{1}{n + 1}\sum_{i = 1}^{n}\sin \frac{i}{n}\pi = \lim_{n\to \infty}\frac{n}{(n + 1)\pi}\frac{\pi}{n}\sum_{i = 1}^{n}\sin \frac{i}{n}\pi = \frac{1}{\pi}\int_0^\pi \sin xdx = \frac{2}{\pi},$ $\lim_{n\to \infty}\frac{1}{n}\sum_{i = 1}^{n}\sin \frac{i}{n}\pi = \lim_{n\to \infty}\frac{1}{\pi}\frac{\pi}{n}\sum_{i = 1}^{n}\sin \frac{i}{n}\pi = \frac{1}{\pi}\int_0^\pi \sin xdx = \frac{2}{\pi}.$ 所以所求极限是 $\frac{2}{\pi}.$
