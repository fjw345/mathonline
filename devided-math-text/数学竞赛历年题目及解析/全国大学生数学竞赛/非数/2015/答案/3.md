证明 1. 若 $\beta = 0$。
对于 $\forall x \in (a, b)$，有
$f'(x) = \alpha f(x)$，$f''(x) = \alpha f'(x) = \alpha^2 f(x), \cdots, f^{(n)}(x) = \alpha^n f(x)$。
从而 $f(x)$ 在 $(a, b)$ 内无穷次可导。……4 分
2. 若 $\beta \neq 0$。对于 $\forall x \in (a, b)$，有
$f''(x) = \frac{f'(x) - \alpha f(x)}{\beta} = A_1 f'(x) + B_1 f(x),$ (1)
其中 $A_1 = 1 / \beta, B_1 = \alpha / \beta$。……6 分因为（1）右端可导，从而
$f'''(x) = A_1 f''(x) + B_1 f'(x)$。……8 分设 $f^{(n)}(x) = A_1 f^{(n-1)}(x) + B_1 f^{(n-2)}(x), n > 1$，则 $f^{(n+1)}(x) = A_1 f^{(n)}(x) + B_1 f^{(n-1)}(x)$。
故 $f(x)$ 任意阶可导。……12 分
