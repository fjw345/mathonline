【解】由 $u = x$ ，$v = \frac{1}{y} -\frac{1}{x}$ 解得 $x = u$ ，$y = \frac{u}{uv + 1}$ ，且 $w = \frac{1}{z} -\frac{1}{u}$ ，所以$\frac{\partial w}{\partial u} = \frac{\partial}{\partial u}\left(\frac{1}{z} -\frac{1}{u}\right) = -\frac{1}{z^2}\cdot \frac{\partial z}{\partial u} +\frac{1}{u^2} = -\frac{1}{z^2}\left(\frac{\partial z}{\partial x}\cdot \frac{\partial x}{\partial u} +\frac{\partial z}{\partial y}\cdot \frac{\partial y}{\partial u}\right) + \frac{1}{u^2}$ $= -\frac{1}{z^2}\left(\frac{\partial z}{\partial x} +\frac{\partial z}{\partial y}\cdot \frac{uv + 1 - uv}{(uv + 1)^2}\right) + \frac{1}{u^2} = -\frac{1}{z^2}\left(\frac{\partial z}{\partial x} +\frac{\partial z}{\partial y}\cdot \frac{1}{(uv + 1)^2}\right) + \frac{1}{u^2}$ $= -\frac{1}{z^2}\left(\frac{\partial z}{\partial x} +\frac{\partial z}{\partial y}\cdot \frac{y^2}{u^2}\right) + \frac{1}{u^2} = -\frac{1}{z^2u^2}\left(x^2\frac{\partial z}{\partial x} +y^2\frac{\partial z}{\partial y}\right) + \frac{1}{u^2} = -\frac{1}{u^2}.$ 此 $\left.\frac{\partial w}{\partial u}\right|_{\substack{u = 2\\ v = 1}} = -\frac{1}{4}.$
