解答. 由于曲线 $y = 3ax^2 + 2bx + \ln c$ 经过 (0,0) 点，故 $\ln c = 0, c = 1$. D 的面积 $A = \int_0^1 (3ax^2 + 2bx)\mathrm{d}x = a + b = 1$. …… (4 分)
D 绕 x 轴一周所得到的旋转体体积
$V = \pi \int_{0}^{1}(3ax^{2} + 2bx)^{2}\mathrm{d}x$
$= \pi (\frac{9}{5}a^{2} + 3ab + \frac{4}{3}b^{2})$
$= \pi (\frac{2}{15}a^{2} + \frac{1}{3}a + \frac{4}{3}).$
……… (10 分)
$V'(a) = \pi (\frac{4}{15}a + \frac{1}{3}).$
不难得到，当 $a = -\frac{5}{4}$ 时，旋转体得体积最小，此时，$b = \frac{9}{4}, c = 1$. (14分)
注:推导最小值点时，用其他办法如配方也可以.
