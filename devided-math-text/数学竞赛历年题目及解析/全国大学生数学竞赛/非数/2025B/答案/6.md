3. 根据积分中值定理，存在 $c \in [a, b]$，使得 $A = \frac{1}{b - a} \int_{a}^{b} f(x) \mathrm{d}x = f(c)$.

(3分)

先后利用Newton-Leibniz公式与Cauchy积分不等式，得

$|f(x) - A|^{2} = |f(x) - f(c)|^{2} = \left(\int_{c}^{x} f'(t) \mathrm{d}t\right)^{2}$

$\leqslant \left|\int_{c}^{x} 1^{2} \mathrm{d}t \int_{c}^{x} |f'(t)|^{2} \mathrm{d}t\right| \leqslant |x - c| \int_{a}^{b} |f'(t)|^{2} \mathrm{d}t.$

所以

$\int_{a}^{b} |f(x) - A|^{2} \mathrm{d}x \leqslant \int_{a}^{b} |x - c| \mathrm{d}x \int_{a}^{b} |f'(x)|^{2} \mathrm{d}x.$

(9分)

易知

$\begin{aligned}&\int_{a}^{b}|x - c|\mathrm{d}x = \int_{a}^{c}|x - c|\mathrm{d}x + \int_{c}^{b}|x - c|\mathrm{d}x = \int_{a}^{c}(c - x)\mathrm{d}x + \int_{c}^{b}(x - c)\mathrm{d}x \\&= \frac{1}{2}(a - c)^{2} + \frac{1}{2}(b - c)^{2} = \frac{1}{2}[(a - c)^{2} + (b - c)^{2}].\end{aligned}$

令 $g(t) = (a - t)^{2} + (b - t)^{2}$，易知 $g(t)$ 在 $[a, b]$ 上的最大值为 $(a - b)^{2}$. 所以

$\int_{a}^{b}|x - c|\mathrm{d}x \leqslant \frac{(a - b)^{2}}{2},$

这就证明了

$\int_{a}^{b}|f(x) - A|^{2}\mathrm{d}x \leqslant \frac{(a - b)^{2}}{2}\int_{a}^{b}|f'(x)|^{2}\mathrm{d}x.$

(14分)
