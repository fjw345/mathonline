【解析】由题知， $X$ 的概率密度为$f_{X}(x;\theta) = \left\{ \begin{array}{ll} \frac{1}{\theta} e^{-\frac{x}{\theta}}, & x > 0\\ 0, & \text{其他} \end{array} \right.$
$Y$ 的概率密度为 $f_{Y}(y;\theta) = \left\{ \begin{array}{ll}\frac{1}{2\theta} e^{-\frac{y}{2\theta}}, & y > 0,\\ 0, & \text{其他} \end{array} \right.$
令 $L = \prod_{i = 1}^{n}f_{X}(x_{i};\theta)\prod_{j = 1}^{m}f_{Y}(y_{j};\theta) = \prod_{i = 1}^{n}\frac{1}{\theta} e^{-\frac{x_{i}}{\theta}}\prod_{j = 1}^{m}\frac{1}{2\theta} e^{-\frac{y_{j}}{2\theta}}(x_{i} > 0,y_{j} > 0,i = 1,2\dots ,n,j = 1,2,\dots ,m),$
则 $\ln L = \sum_{i = 1}^{n}(-\ln \theta -\frac{x_i}{\theta}) + \sum_{j = 1}^{m}(\ln \frac{1}{2} -\ln \theta -\frac{y_j}{2\theta})$
所以 $\frac{d\ln L}{d\theta} = \sum_{i = 1}^{n}(-\frac{1}{\theta} +\frac{x_i}{\theta^2}) + \sum_{j = 1}^{m}(-\frac{1}{\theta} +\frac{y_j}{2\theta^2})$
$= -\frac{m + n}{\theta} +\sum_{i = 1}^{n}\frac{x_i}{\theta^2} +\sum_{j = 1}^{m}\frac{y_j}{2\theta^2} = 0\Rightarrow \hat{\theta} = \frac{1}{m + n}\Bigg(\sum_{i = 1}^{n}x_{i} + \frac{1}{2}\sum_{j = 1}^{m}y_{j}\Bigg)$
所以， $\theta$ 的最大似然估计量为 $\hat{\theta} = \frac{1}{m + n}\Bigg(\sum_{i = 1}^{n}X_{i} + \frac{1}{2}\sum_{j = 1}^{m}Y_{j}\Bigg)$
$D(\hat{\theta}) = \frac{1}{(m + n)^2}\Bigg(\sum_{i = 1}^{n}DX_i + \frac{1}{4}\sum_{j = 1}^{m}DY_j\Bigg) = \frac{1}{(m + n)^2}\Bigg(nDX + \frac{1}{4} mDY\Bigg)$
$= \frac{1}{(m + n)^2}\Bigg(n\theta^2 +\frac{1}{4} m4\theta^2\Bigg) = \frac{\theta^2}{m + n}.$
