【答案】

(I) $f(x,y) = \begin{cases} 3, & 0 < x < 1, x^2 < y < \sqrt{x} \\ 0, & \text{其他} \end{cases}$

(II) $U$ 与 $X$ 不独立，因为 $P\left\{U \leq \frac{1}{2}, X \leq \frac{1}{2}\right\} \neq P\left\{U \leq \frac{1}{2}\right\} P\left\{X \leq \frac{1}{2}\right\}$;

(III) $Z$ 的分布函数

$$
F _ {Z} (z) = \left\{ \begin{array}{l} 0, z < 0 \\ \frac {3}{2} z ^ {2} - z ^ {3}, 0 \leq z < 1 \\ \frac {1}{2} + 2 (z - 1) ^ {\frac {3}{2}} - \frac {3}{2} (z - 1) ^ {2}, 1 \leq z < 2 \\ 1, z \geq 2 \end{array} \right.
$$

【解析】（1）区域D的面积 $s(D) = \int_0^1 (\sqrt{x} -x^2) = \frac{1}{3}$ ，因为 $f(x,y)$ 服从区域D上的均匀分布，所以

$$
f (x, y) = \left\{ \begin{array}{l l} 3 & x ^ {2} < y < \sqrt {x} \\ 0 & \text {其他} \end{array} . \right.
$$

(2) X 与 U 不独立.

因为 $P\left\{U \leq \frac{1}{2}, X \leq \frac{1}{2}\right\} = P\left\{U = 0, X \leq \frac{1}{2}\right\} = P\left\{X > Y, X \leq \frac{1}{2}\right\} = \frac{1}{12}$

$$
P \left\{U \leq \frac {1}{2} \right\} = \frac {1}{2}, P \left\{X \leq \frac {1}{2} \right\} = \frac {1}{2}
$$

所以 $P\left\{U \leq \frac{1}{2}, X \leq \frac{1}{2}\right\} \neq P\left\{U \leq \frac{1}{2}\right\} P\left\{X \leq \frac{1}{2}\right\}$, 故 $X$ 与 $U$ 不独立。
