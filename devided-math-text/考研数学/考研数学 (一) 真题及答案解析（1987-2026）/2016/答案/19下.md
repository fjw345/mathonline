因此，$\sum_{n=1}^{\infty}\left(x_{n+1}-x_n\right)$ 绝对收敛；

(2) $\sum_{n=1}^{\infty}\left(x_{n+1}-x_n\right)$ 的前 $n$ 项和记为 $S_n$

易知，$S_n = x_{n+1} - x_1$，由第一问可知 $S_n$ 极限存在，因此 $\lim_{n\to\infty}x_n = A$ 存在

$x_{n+1} = f(x_n) = f(x_n) - f(0) + 1$

$= f'(\xi)x_n + 1 (*)$

i) 由已知 $0 < f'(x) < \frac{1}{2}$，易知 $x_{n+1} = f'(\xi)x_n + 1 < \frac{1}{2}x_n = 1$

不等式两边取极限，可知 $A < \frac{1}{2}A + 1$，即 $A < 2$；

ii) 若 $A = 0$，则 (\*) 矛盾；

iii) 若 $A < 0$，则由 (\*) 可知 $(1 - f'(\xi))A = 1$，而 $0 < f'(x) < \frac{1}{2}$，显然矛盾综上，$0 < A < 2$
