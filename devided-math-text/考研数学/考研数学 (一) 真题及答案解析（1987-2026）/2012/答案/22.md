(1) $P(X = 2Y) = P(X = 0,Y = 0) + P(X = 2,Y = 1) = \frac{1}{4} +0 = \frac{1}{4}$

(2) $cov(X-Y,Y)=cov(X,Y)-cov(Y,Y)$

$\operatorname{cov}(X,Y) = EXY - EXEY$ ，其中 $EX = \frac{2}{3}, EX^2 = 1, EY = 1, EY^2 = \frac{5}{3}, DX = EX^2 - (EX)^2 = 1 - \frac{4}{9} = \frac{5}{9}$ $DY = EY^2 - (EY)^2 = \frac{5}{3} - 1 = \frac{2}{3}, EXY = \frac{2}{3}$ 所以，$\operatorname{cov}(X,Y) = 0$ ，$\operatorname{cov}(Y,Y) = DY = \frac{2}{3}$，$\operatorname{cov}(X - Y,Y) = -\frac{2}{3}, \rho_{XY} = 0$。
