【解析】:设圆 $x^{2} + y^{2} = 2x$ 为圆 $C_1$ ，圆 $x^{2} + y^{2} = 4$ 为圆 $C_2$ ，下补线利用格林公式即可，设所补直线 $L_{1}$ 为$x = 0(0\leq y\leq 2)$ ，下用格林格林公式得:原式$= \int_{L + L_{i}}3x^{2}y\mathrm{d}x + (x^{3} + x - 2y)\mathrm{d}y - \int_{L_{i}}3x^{2}y\mathrm{d}x + (x^{3} + x - 2y)\mathrm{d}y$
$= \iint_{D}(3x^{2} + 1 - 3x^{2})\mathrm{d}x\mathrm{d}y - \int_{2}^{0} - 2y\mathrm{d}y$
$= \frac{1}{4} S_{C_2} - \frac{1}{2} S_{C_1} + 4 = \frac{\pi}{2} -4$
