$f_{xx}^{\prime \prime} = e^{x + y}(2x + 2x^{2} + y + \frac{x^{3}}{3})\quad f_{xy}^{\prime \prime} = e^{x + y}(1 + x^{2} + y + \frac{x^{3}}{3})\quad f_{yy}^{\prime \prime} = e^{x + y}(2 + y + \frac{x^{3}}{3})$ $A = f_{xx}^{\prime \prime}\big|_{(1, - \frac{4}{3})} = 3e^{\frac{-1}{3}},\quad B = f_{xy}^{\prime \prime}\big|_{(1, - \frac{4}{3})} = e^{\frac{-1}{3}},\quad C = f_{yy}^{\prime \prime}\big|_{(1, - \frac{4}{3})} = e^{\frac{-1}{3}}$ $AC - B^{2} = 3e^{\frac{-2}{3}} - e^{\frac{-2}{3}} = 2e^{\frac{-2}{3}} > 0$ 又 $A > 0$ 所以 $\left(1, - \frac{4}{3}\right)$ 为 $f(x,y)$ 的极小值点，极小值为 $f\left(1, - \frac{4}{3}\right) = -e^{\frac{-1}{3}}$ $A = f_{xx}^{\prime \prime}\big|_{(1, - \frac{2}{3})} = -e^{\frac{-5}{3}},\quad B = f_{xy}^{\prime \prime}\big|_{(1, - \frac{2}{3})} = e^{\frac{-5}{3}},\quad C = f_{yy}^{\prime \prime}\big|_{(1, - \frac{2}{3})} = e^{\frac{-5}{3}}$ 因为 $AC - B^{2} < 0$ ，所以 $(-1, - \frac{2}{3})$ 不是 $f(x,y)$ 的极值点.
