【解析】方法一:取矩阵 $A = \begin{pmatrix} 1 & 0 & 0 \\ 0 & -1 & 0 \\ 0 & 0 & 1 \end{pmatrix}$，满足题设条件，$\left|A\right| = -1$。
方法二:$A^{*} = -A^{T}$，则 $\left|A^{*}\right| = \left| -A^{T}\right|$，整理得到 $\left|A\right|^{3-1} = (-1)^{3}\left|A\right|$，即 $\left|A\right| = -1$ 或者 $\left|A\right| = 0$。$\left|A\right| = a_{i1}A_{i1} + a_{i2}A_{i2} + a_{i3}A_{i3} = -\left(a_{i1}^{2} + a_{i2}^{2} + a_{i3}^{2}\right) \leq 0$
又因为 $A \neq O$，所以至少有一个 $a_{ij} \neq 0$，所以
$\left|A\right| = a_{i1}A_{i1} + a_{i2}A_{i2} + a_{i3}A_{i3} = -\left(a_{i1}^{2} + a_{i2}^{2} + a_{i3}^{2}\right) < 0$
从而 $\left|A\right| = -1$。
