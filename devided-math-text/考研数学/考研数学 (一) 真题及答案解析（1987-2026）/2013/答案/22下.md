当 $1 \leq y < 2$ 时，$F(y) = P\{X \leq y, 1 < X < 2\} + P\{X \geq 2\} = P\{1 < X \leq y\} + P\{X \geq 2\}$

$= \int_{1}^{y} \frac{1}{9} x^{2} dx + \int_{2}^{3} \frac{1}{9} x^{2} dx = \frac{1}{27}(y^{3} - 1) + \frac{1}{27}(3^{3} - 2^{3}) = \frac{1}{27}(y^{3} + 18)$

当 $y \geq 2$ 时，$F(y) = P\{X \leq 1\} + P\{1 < X < 2\} + P\{X \geq 2\} = 1$
