【解析】因为总体 $X$ 服从正态分布，故设 $X$ 的概率密度为 $f(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x - \mu_0)^2}{2\sigma^2}}$，$-\infty < x < +\infty$.(I)似然函数$L(\sigma^2) = \prod_{i=1}^{n} f(x_i; \sigma^2) = \prod_{i=1}^{n} \left[ \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x_i - \mu_0)^2}{2\sigma^2}} \right] = (2\pi\sigma^2)^{-\frac{n}{2}} \left[ e^{-\frac{1}{2\sigma^2} \sum_{i=1}^{n}(x_i - \mu_0)^2}; \right.$ 取对数:$\ln L(\sigma^2) = -\frac{n}{2}\ln(2\pi\sigma^2) - \sum_{i=1}^{n} \frac{(x_i - \mu_0)^2}{2\sigma^2};$ 求导:$\frac{d\ln L(\sigma^2)}{d(\sigma^2)} = -\frac{n}{2\sigma^2} + \sum_{i=1}^{n} \frac{(x_i - \mu_0)^2}{2(\sigma^2)^2} = \frac{1}{2(\sigma^2)^2} \sum_{i=1}^{n} [(x_i - \mu_0)^2 - \sigma^2].$ 令 $\frac{d\ln L(\sigma^2)}{d(\sigma^2)} = 0$ ，解得 $\sigma^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i - \mu_0)^2.$ $\sigma^2$ 的最大似然估计量为 $\hat{\sigma^2} = \frac{1}{n}\sum_{i=1}^{n}(X_i - \mu_0)^2.$
