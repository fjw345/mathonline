（II）设 $a_{n} = 1 + \frac{1}{2} +\frac{1}{3} +\dots +\frac{1}{n} -\ln n = \sum_{k = 1}^{\infty}\frac{1}{k} -\ln n.$

先证数列 $\{a_{n}\}$ 单调递减.

$a _ {n + 1} - a _ {n} = \left[ \sum_ {\hat {k} = 1} ^ {n + 1} \frac {1}{k} - \ln (n + 1) \right] - \left[ \sum_ {\hat {k} = 1} ^ {n} \frac {1}{k} - \ln n \right] = \frac {1}{n + 1} + \ln \left(\frac {n}{n + 1}\right) = \frac {1}{n + 1} - \ln \left(1 + \frac {1}{n}\right), \quad ↔$

利用（I）的结论可以得到 $\frac{1}{n + 1} < \ln (1 + \frac{1}{n})$ ，所以 $\frac{1}{n + 1} -\ln \left(1 + \frac{1}{n}\right) < 0$ 得到 $a_{n + 1} < a_n$ ，即数列 $\{a_n\}$ 单调递减.

再证数列 $\left\{a_{n}\right\}$ 有下界.

$a _ {n} = \sum_ {k = 1} ^ {n} \frac {1}{k} - \ln n > \sum_ {k = 1} ^ {n} \ln \left(1 + \frac {1}{k}\right) - \ln n, \quad ↔$

$$
\sum_ {k = 1} ^ {n} \ln \left(1 + \frac {1}{k}\right) = \ln \prod_ {k = 1} ^ {n} \left(\frac {k + 1}{k}\right) = \ln \left(\frac {2}{1} \cdot \frac {3}{2} \cdot \frac {4}{3} \dots \frac {n + 1}{n}\right) = \ln (n + 1),
$$

$$
a _ {n} = \sum_ {\kappa = 1} ^ {n} \frac {1}{k} - \ln n > \sum_ {\kappa = 1} ^ {n} \ln \left(1 + \frac {1}{k}\right) - \ln n > \ln (n + 1) - \ln n > 0.
$$

得到数列 $\{a_{n}\}$ 有下界.利用单调递减数列且有下界得到 $\{a_{n}\}$ 收敛.
