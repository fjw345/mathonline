$m \leq f''(\eta_1) \leq M; m \leq f''(\eta_2) \leq M$；从而 $m \leq \frac{f''(\eta_1) + f''(\eta_2)}{2} \leq M$；

由介值定理得:存在 $\xi \in [\eta_2, \eta_1] \subset (-a, a)$，有 $\frac{f''(\eta_1) + f''(\eta_2)}{2} = f''(\xi)$，代入③得:

$f(a) + f(-a) = a^2 f''(\xi), \quad f''(\xi) = \frac{f(a) + f(-a)}{a^2}$

（Ⅱ）证明:设 $f(x)$ 在 $x = x_0 \in (-a, a)$ 取极值，且 $f(x)$ 在 $x = x_0$ 可导，则 $f'(x_0) = 0$。

又 $f(x) = f(x_0) + f'(x_0)(x - x_0) + \frac{f''(\gamma)}{2!}(x - x_0)^2 = f(x_0) + \frac{f''(\gamma)}{2!}(x - x_0)^2$，$\gamma$ 介于 0 与 $x$ 之间，则 $f(-a) = f(x_0) + \frac{f''(\gamma_1)}{2!}(-a - x_0)^2, \quad -a < \gamma_1 < 0$

$f(a) = f(x_0) + \frac{f''(\gamma_2)}{2!}(a - x_0)^2, \quad 0 < \gamma_2 < a$

从而 $\left|f(a) - f(-a)\right| = \left|\frac{1}{2}(a - x_0)^2 f''(\gamma_2) - \frac{1}{2}(a + x_0)^2 f''(\gamma_1)\right|$

$\leq \frac{1}{2}\left|(a - x_0)^2 f''(\gamma_2)\right| + \frac{1}{2}\left|(a + x_0)^2 f''(\gamma_1)\right|$

又 $\left|f''(x)\right|$ 连续，设 $M = \max \left\{\left|f''(\gamma_1)\right|, \left|f''(\gamma_2)\right|\right\}$，则

$\left|f(a) - f(-a)\right| \leq \frac{1}{2} M(a + x_0)^2 + \frac{1}{2} M(a - x_0)^2 \leq M(a^2 + x_0^2)$

又 $x_0 \in (-a, a)$，则 $\left|f(a) - f(-a)\right| \leq M(a^2 + x_0^2) \leq 2Ma^2$，则 $M \geq \frac{1}{2a^2}\left|f(a) - f(-a)\right|$，即存在 $\eta = \gamma_1$ 或 $\eta = \gamma_2 \in (-a, a)$，有

$$
\left| f ^ {\prime \prime} (\eta) \right| \geq \frac {1}{2 a ^ {2}} \left| f (a) - f (- a) \right|.
$$
