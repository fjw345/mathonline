[解答] $f_{1}(x) = \frac{1}{\sqrt{2\pi}} e^{-\frac{x^{2}}{2}} (-\infty < x < +\infty), f_{2}(x) = \begin{cases} \frac{1}{4}, -1 \leq x \leq 3, \\ 0, \text{其他} \end{cases}$

因为 $f(x)$ 为概率密度函数，所以 $\int_{-\infty}^{+\infty} f(x) dx = 1$，

而 $\int_{-\infty}^{+\infty} f(x) dx = a \int_{-\infty}^{0} f_{1}(x) dx + b \int_{0}^{+\infty} f_{2}(x) dx = \frac{a}{2} + b \int_{0}^{3} \frac{1}{4} dx = \frac{a}{2} + \frac{3}{4} b,$

所以 $\frac{a}{2} + \frac{3}{4} = 1$，即 $2a + 3b = 4$，选 (A)。
