方法一:补充 $L_{1}:y = 0$ （起点(1,0)，终点(-1,0)），由格林公式

$$
\int_ {L} x y d x + x ^ {2} d y = \oint_ {L + L _ {1}} x y d x + x ^ {2} d y - \int_ {L _ {1}} x y d x + x ^ {2} d y,
$$

而 $\int_{L + L_1}xydx + x^2 dy = \iint_{D}xdxdy = \int_0^1 dy\int_{y - 1}^{1 - y}xdx = 0,$

$\int_{L_1}xydx + x^2 dy = \int_{L_1}xydx = 0$ ，所以原式 $= 0$ 。

方法二:

$$
\int_ {L} x y d x + x ^ {2} d y = \int_ {- 1} ^ {0} [ x (1 + x) + x ^ {2} ] d x + \int_ {0} ^ {1} [ x (1 - x) - x ^ {2} ] d x = 0.
$$
