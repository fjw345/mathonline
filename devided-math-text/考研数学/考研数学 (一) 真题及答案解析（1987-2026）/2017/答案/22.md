【答案】(I) $P\{Y\leq EY\}=\frac{4}{9}$ ;(Ⅲ) $f_{Z}(z)=\left\{\begin{aligned}&z,&0<z<1\\&z-2,2<z<3\end{aligned}\right.$

【解析】

(I) $E(Y) = \int_{0}^{1}y2ydy = \frac{2}{3}$

$$
P (Y \leq E Y) = P (Y \leq \frac {2}{3}) = \int_ {0} ^ {\frac {2}{3}} 2 y d y = \frac {4}{9}
$$

$(\Pi)F_{z}(Z) = P(Z \leq z) = P(X + Y \leq z)$ $= P(X + Y \leq z, X = 0) + P(X + Y \leq z, X = 2)$ $= P(Y \leq z, X = 0) + P(Y \leq z - 2, X = 2)$ $= \frac{1}{2} P(Y \leq z) + \frac{1}{2} P(Y \leq z - 2)$

(1) 当 z < 0, z - 2 < 0，而 z < 0，则 $F_{z}(Z) = 0$

(2) 当 $z-2 \geq 1, z > 1$ ，即 $z \geq 3$ 时， $F_{z}(Z) = 1 \leftrightarrow$

(3) 当 $0 \leq z < 1$ 时， $F_{z}(Z) = \frac{1}{2} z^{2}$

(4) 当 $1 \leq z < 2$ 时，$F_{z}(Z) = \frac{1}{2}$

(5) 当 $2 \leq z < 3$ 时， $F_{z}(Z) = \frac{1}{2} + \frac{1}{2}(z - 2)^{2}$

所以综上 $F_{z}(Z) = \left\{ \begin{array}{l}0\quad z < 0\\ \frac{1}{2} z^{2},0\leq z < 1\\ \frac{1}{2},1\leq z < 2\\ \frac{1}{2} +\frac{1}{2} (z - 2)^{2},2\leq z < 3\\ 1,z\geq 3 \end{array} \right.$

所以 $f_{z}(Z) = \left[F_{z}(Z)\right] = \left\{ \begin{array}{ll}z & 0 < z < 1\\ z - 2 & 2 < z < 3 \end{array} \right.$
