16、解:$\because x^{2} + y^{2}y' = 1 - y'$
$\therefore y' = \frac{1 - x^2}{y^2 + 1}$
令 $y' = 0, \therefore x = \pm 1$
$\therefore y'' = \frac{-2x(y^2 + 1) - (1 - x^2) \cdot 2yy'}{(y^2 + 1)^2}$
又 $\because y'(1) = y'(-1) = 0$
$\therefore y''(1) = \frac{-2}{y^2(1) + 1} \langle 0, \therefore y(1)$ 为极大值
$y''(-1) = \frac{2}{y^2(1) + 1} \rangle 0, y(-1)$ 为极小值
下求极值
$\because y' = \frac{1 - x^2}{y^2 + 1}, \therefore (y^2 + 1)dy = (1 - x^2)dx, \therefore \int (y^2 + 1)dy = \int (1 - x^2)dx$
$\therefore \frac{1}{3}y^3 + y = x - \frac{1}{3}x^3 + c$
又 $y(2) = 0$
$\therefore c = \frac{2}{3}$
$\therefore \frac{1}{3}y^3 + y = x - \frac{1}{3}x^3 + \frac{2}{3}$
