$\lim_{x\to \infty}y - x = \lim_{x\to 0}x\ln \left(e + \frac{1}{x - 1}\right) - x = \lim_{x\to \infty}x\left(\ln \left(e + \frac{1}{x - 1}\right) - 1\right)$
$= \lim_{x\to \infty}\frac{\ln\left(1 + \frac{1}{(x - 1)e}\right)}{\frac{1}{x}} = \lim_{x\to \infty}\frac{\frac{1}{(x - 1)e}}{\frac{1}{x}} = \lim_{x\to \infty}\frac{x}{(x - 1)e} = \frac{1}{e}$
$y = x + \frac{1}{e}$ .选B.
