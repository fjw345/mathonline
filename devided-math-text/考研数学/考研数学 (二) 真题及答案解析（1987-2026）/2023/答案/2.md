【答案】D.

$$
\text {【解析】} F (x) = \left\{ \begin{array}{l l} \ln \left| x + \sqrt {x ^ {2} + 1} \right| + C _ {1}, & x \leq 0 \\ \int (x + 1) \cos x d x = \int (x + 1) d \sin x = (x + 1) \sin x + \cos x + C _ {2}, & x > 0 \end{array} \right.
$$

$F(x)$ 在 $x = 0$ 处连续， $C_1 = C_2 + 1$ ，若 $C_2 = 0$ ，则 $C_1 = 1$ ，选D.
