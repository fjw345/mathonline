已知常数 $k \geq \ln 2 - 1$. 证明:$(x - 1)(x - \ln^2 x + 2k \ln x - 1) \geq 0$.

【解析】设 $F(x) = x - \ln^2 x + 2k \ln x - 1, x > 0$ 则

$F'(x) = 1 - \frac{2 \ln x}{x} + \frac{2k}{x} = \frac{x - 2 \ln x + 2k}{x}$

令 $G(x) = x - 2 \ln x + 2k$, 则 $G'(x) = 1 - \frac{2}{x}$,

当 $0 < x < x$ 时，$G'(x) < 0$, 又 $G(2) = 0$,

所以 $G(x) > 0 \Rightarrow F'(x) > 0 \Rightarrow G(x)$ 单调递增当 $x > 2$ 时，$G'(x) > 0$, 又 $G(2) = 0$,

所以 $G(x) > 0 \Rightarrow F'(x) > 0 \Rightarrow G(x)$ 单调递增综上所述:$F(x)$ 在 $x > 0$ 时单调递增，又因为 $F(1) = 0$，所以 $0 < x < 1$ 时，$F(x) < 0; x > 1$ 时，$F(x) > 0$

即 $(x - 1)F(x) \geq 0$, 原不等式得证.
