【解析】由于 $\frac{3x + 6}{(x - 1)^2(x^2 + x + 1)} = -\frac{2}{x - 1} +\frac{3}{(x - 1)^2} +\frac{2x + 1}{x^2 + x + 1}$
故原积分可化为: $\int \left[-\frac{2}{x - 1} +\frac{3}{(x - 1)^2} +\frac{2x + 1}{x^2 + x + 1}\right]dx = -2\int \frac{1}{x - 1} dx + 3\int \frac{1}{(x - 1)^2} dx + \int \frac{2x + 1}{x^2 + x + 1} dx$
$= -2\ln |x - 1| - \frac{3}{x - 1} +\int \frac{1}{x^2 + x + 1} d(x^2 +x + 1)$
$= -2\ln |x - 1| - \frac{3}{x - 1} +\ln (x^{2} + x + 1) + C$
