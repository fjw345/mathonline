【答案】 $\frac{8\sqrt{3}}{9}\pi$
【解析】 $\int_0^1\frac{2x + 3}{x^2 - x + 1} dx$
$= \int_0^1\frac{2x - 1}{x^2 - x + 1} dx + \int_0^1\frac{4}{x^2 - x + 1} dx$
$= \ln (x^{2} - x + 1)\Big|_{0}^{1} + 4\int_{0}^{1}\frac{1}{(x - \frac{1}{2})^2 + (\frac{\sqrt{3}}{2})^2} dx$
$= 0 + 4\cdot \frac{1}{\frac{\sqrt{3}}{2}}\arctan \left.\frac{x - \frac{1}{2}}{\frac{\sqrt{3}}{2}}\right|_{0}^{1} = \frac{8\sqrt{3}}{3}\arctan \left.\frac{2x - 1}{\sqrt{3}}\right|_{0}^{1} = \frac{8\sqrt{3}}{3}\cdot \frac{\pi}{3} = \frac{8\sqrt{3}}{9}\pi .$
