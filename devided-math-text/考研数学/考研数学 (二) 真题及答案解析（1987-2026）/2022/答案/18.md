【解析】由题意可知 $y' - \frac{2}{x}y = \frac{2\ln x - 1}{2x}$，则

$y(x) = e^{-\int \left(-\frac{2}{x}\right)dx} \left[ \int \frac{2\ln x - 1}{2x} e^{\int \left(-\frac{2}{x}\right)dx} dx + C \right] = x^2 \left[ \int \frac{2\ln x - 1}{2x^3} dx + C \right] = -\frac{1}{2} \ln x + Cx^2$，其中 $C$ 为任意常数，又 $y(1) = \frac{1}{4}$，则 $C = \frac{1}{4}$，故 $y(x) = -\frac{1}{2} \ln x + \frac{1}{4} x^2$，则弧长为

$L = \int_{1}^{e} \sqrt{1 + (y')^2} dx = \int_{1}^{e} \sqrt{1 + (\frac{x}{2} - \frac{1}{2x})^2} dx = \int_{1}^{e} \sqrt{(\frac{x}{2} + \frac{1}{2x})^2} dx$

$= \int_{1}^{e} \left( \frac{x}{2} + \frac{1}{2x} \right) dx = \left( \frac{1}{4} x^2 + \frac{1}{2} \ln x \right) \bigg|_1^e$

$= \frac{1}{4}(e^2 + 1)$.
