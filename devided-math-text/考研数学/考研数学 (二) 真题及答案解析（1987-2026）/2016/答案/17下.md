令 $\frac{\partial z}{\partial x}=0,\frac{\partial z}{\partial y}=0$ (3) 得: $\left\{\begin{aligned}x&=-1\\ y&=-1\\ z&=1\end{aligned}\right.$ (4)

又对（1）关于 $x$ 求偏导数，（1）对 $y$ 求偏导数，（2）对 $y$ 求偏导数，再把（3），（4）代入即得:$2z + (x^{2} + y^{2})\frac{\partial^{2}z}{\partial x^{2}} + \frac{1}{z}\frac{\partial^{2}z}{\partial x^{2}} = 0$
$2z + (x^{2} + y^{2})\frac{\partial^{2}z}{\partial y^{2}} + \frac{1}{z}\frac{\partial^{2}z}{\partial y^{2}} = 0$
$(x^{2} + y^{2})\frac{\partial^{2}z}{\partial x\partial y} + \frac{1}{z}\frac{\partial^{2}z}{\partial x\partial y} = 0$
得:$A = \frac{\partial^2 z}{\partial x^2} = -\frac{2}{3}, B = \frac{\partial^2 z}{\partial x\partial y} = 0, C = \frac{\partial^2 z}{\partial y^2} = -\frac{2}{3}$

又 $AC - B^{2} > 0, A < 0$ ，故 $z = z(x, y)$ 在 $(-1, -1)$ 取得极大值，极大值为 $z(-1, -1) = 1$
