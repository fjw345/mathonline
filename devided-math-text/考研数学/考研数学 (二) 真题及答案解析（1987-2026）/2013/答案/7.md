(7) 设矩阵 A, B, C 均为 n 阶矩阵，若 AB = C，且 C 可逆，则（）
(A) 矩阵 C 的行向量组与矩阵 A 的行向量组等价
(B) 矩阵 C 的列向量组与矩阵 A 的列向量组等价
(C) 矩阵 C 的行向量组与矩阵 B 的行向量组等价
(D) 矩阵 C 的行向量组与矩阵 B 的列向量组等价
【答案】(B)
【解析】由 C = AB 可知 C 的列向量组可以由 A 的列向量组线性表示，又 B 可逆，故有 $A = CB^{-1}$ ，从而 A 的列向量组也可以由 C 的列向量组线性表示，故根据向量组等价的定义可知正确选项为 (B)。
