【解析】: $f(x,y) = xe - \frac{x^2 + y^2}{2}$ 先求函数的驻点. $f_{x}^{\prime}(x,y) = e - x = 0,f_{y}^{\prime}(x,y) = -y = 0$ ，解得函数为驻点为 $(e,0)$ 又 $A = f_{xx}^{\prime}(e,0) = -1,B = f_{xy}^{\prime}(e,0) = 0,C = f_{yy}^{\prime}(e,0) = -1,$ 所以 $B^{2} - AC < 0,A < 0$ ，故 $f(x,y)$ 在点 $(e,0)$ 处取得极大值 $f(e,0) = \frac{1}{2} e^2.$
