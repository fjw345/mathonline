求 $f(x) = x + 8y - xy$ 的极值。解:$\begin{cases} f_x'(x, y) = 3x^2 - y = 0 \\ f_y'(x, y) = 24y^2 - x = 0 \end{cases}$ 所以 $\begin{cases} x = 0 \\ y = 0 \end{cases}$ 或 $\begin{cases} x = \frac{1}{6} \\ y = \frac{1}{12} \end{cases}$ 所以驻点为 $(0,0)$ 或 $\left(\frac{1}{6}, \frac{1}{12}\right)$ $A = f_{xx}''(x, y) = 6x$ $B = f_{xy}''(x, y) = -1$ $C = f_{yy}''(x, y) = 48y$ 代入 $(0,0)$，此时 $AC - B^2 < 0$ 所以不是极值点代入 $\left(\frac{1}{6}, \frac{1}{12}\right)$，$AC - B^2 > 0$ 且 $A > 0$，所以 $f = \left(\frac{1}{6}\right)$

$$
