【解析】:斜率 $k = \lim_{x\to +\infty}\frac{y}{x} = \lim_{x\to +\infty}\frac{\overline{(1 + x)^x}}{x} = \lim_{x\to +\infty}\frac{1}{\left(1 + \frac{1}{x}\right)^x} = \frac{1}{\mathrm{e}}$
$b = \lim_{x\to +\infty}(y - kx) = \lim_{x\to +\infty}\left[\frac{x^{1 + x}}{(1 + x)^x} -\frac{1}{\mathrm{e}} x\right] = \lim_{x\to +\infty}x\left[\frac{1}{\left(1 + \frac{1}{x}\right)^x} -\frac{1}{\mathrm{e}}\right]$
令 $t = \frac{1}{x}\lim_{t\to 0^{+}}\frac{\mathrm{e} - (1 + t)^{\frac{1}{t}}}{\mathrm{e}t(1 + t)^{\frac{1}{t}}} = -\frac{1}{\mathrm{e}^2}\lim_{t\to 0^{+}}\frac{\mathrm{e}^{\frac{1}{t}\ln(1 + t)} - \mathrm{e}}{t} = -\frac{1}{\mathrm{e}}\lim_{t\to 0^{+}}\frac{\mathrm{e}^{\frac{1}{t}\ln(1 + t) - 1} - 1}{t}$
$= -\frac{1}{\mathrm{e}}\lim_{t\to 0^{+}}\frac{\frac{1}{t}\ln(1 + t) - 1}{t} = -\frac{1}{\mathrm{e}}\lim_{t\to 0^{+}}\frac{\ln(1 + t) - t}{t^2} = -\frac{1}{\mathrm{e}}\lim_{t\to 0^{+}}\frac{-\frac{1}{2}t^2}{t^2} = \frac{1}{2\mathrm{e}}$
所以斜渐近线方程为: $y = \frac{1}{\mathrm{e}} x + \frac{1}{2\mathrm{e}}$
