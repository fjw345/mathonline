【解析】:（1） $T$ 的分布函数为

$$
F _ {T} (x) = P \{T \leq x \} = P \{X _ {1} \leq x, X _ {2} \leq x, X _ {3} \leq x \}
$$

$$
\begin{array}{l} = \prod_ {i = 1} ^ {3} P \{X _ {i} \leq x \} \\ = [ F (x) ] ^ {3} \end{array}
$$

$(F(x)$ 为 $X$ 的分布函数）.

则 $T$ 的概率密度为 $f_{T}(x) = 3[F(x)]^{2}f(x) = \left\{ \begin{array}{ll}\frac{9x^{3}}{\theta^{9}} & 0 < x < \theta \\ 0 & \text{其他} \end{array} \right.$

(2) $ET = \int_{-\infty}^{+\infty}xf_{T}(x)dx = \int_{0}^{\sigma}\frac{9x^{\theta}}{\theta^{\theta}} dx = \frac{9\theta}{10}$，则 $E(aT) = aET = \frac{9a}{10}\theta$，可知 $a = \frac{10}{9}$.
