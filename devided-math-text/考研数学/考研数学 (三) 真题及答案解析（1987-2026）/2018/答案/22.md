【解析】(I) $EX = 0, EX^2 = 1, EY = \lambda \Rightarrow E(XZ) = E(X^2Y) = \lambda$

$Cov(X,Z) = E(XZ) - EXEZ = \lambda.$

$Z$ 的取值为 $0, \pm 1, \pm 2, \cdots,$

$P\{Z = 0\} = P\{X = -1, Y = 0\} + P\{X = 1, Y = 0\} = \frac{1}{2}P\{Y = 0\} + \frac{1}{2}P\{Y = 0\} = e^{-\lambda}$

(II) $P\{Z = k\} = P\{X = 1, Y = k\} = \frac{1}{2}P\{Y = k\} = \frac{1}{2}\frac{\lambda^k e^{-\lambda}}{k!}$

$P\{Z = -k\} = P\{X = -1, Y = k\} = \frac{1}{2}P\{Y = k\} = \frac{1}{2}\frac{\lambda^k e^{-\lambda}}{k!}$, 其中$k = 1, 2, \cdots.$
