【解】当 $-1 < x < 1$ 时，$\cos 2x = \sum_{n=0}^{\infty} (-1)^{n} \frac{(2x)^{2n}}{(2n)!} = \sum_{n=0}^{\infty} (-1)^{n} \frac{2^{2n}}{(2n)!} x^{2n}, \frac{1}{1+x} = \sum_{n=0}^{\infty} (-1)^{n} x^{n}$，所以

$-\frac{1}{(1+x)^{2}} = (\frac{1}{1+x})' = \sum_{n=1}^{\infty} (-1)^{n} n x^{n-1} = \sum_{n=0}^{\infty} (-1)^{n+1} (n+1) x^{n}.$

所以 $\sum_{n=0}^{\infty} a_{n} x^{n} = \sum_{n=0}^{\infty} (-1)^{n} \frac{2^{2n}}{(2n)!} x^{2n} + \sum_{n=0}^{\infty} (-1)^{n+1} (n+1) x^{n}.$

故当 $n$ 为偶数时，$a_{n} = (-1)^{\frac{n}{2}} (\frac{2^{n}}{n!}-n-1)$; 当 $n$ 为奇数时，$a_{n} = (-1)^{n+1} (n+1)$.
