$F(x) = \begin{cases} \ln \left(x + \sqrt{1 + x^2}\right) + C_1, & x \leq 0 \\ (x + 1)\sin x + \cos x + C_2, & x > 0 \end{cases}$

由原函数的连续性知: $F(0 - 0) = F(0 + 0)$，得 $C_1 = C_2 + 1$，取 $C_2 = 0$，则 $C_1 = 1$ 答案应选（D）.
