(22)【解法一】利用泊松积分 $\int_{-\infty}^{+\infty}\mathrm{e}^{-t^2}\mathrm{d}t = \sqrt{\pi}$ 可得$1 = \int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty}f(x,y)\mathrm{d}x\mathrm{d}y = A\int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty}\mathrm{e}^{-2x^2 + 2xy - y^2}\mathrm{d}x\mathrm{d}y$ $= A\int_{-\infty}^{+\infty}\mathrm{e}^{-x^2}\mathrm{d}x\int_{-\infty}^{+\infty}\mathrm{e}^{-(y - x)^2}\mathrm{d}y = A\sqrt{\pi}\int_{-\infty}^{+\infty}\mathrm{e}^{-x^2}\mathrm{d}x = A\pi ,$ 计算得知 $A = 1 / \pi .$ $f_{X}(x) = \int_{-\infty}^{+\infty}f(x,y)\mathrm{d}y = \int_{-\infty}^{+\infty}\frac{1}{\pi}\mathrm{e}^{-2x^2 + 2xy - y^2}\mathrm{d}y = \int_{-\infty}^{+\infty}\frac{1}{\pi}\mathrm{e}^{-x^2}\cdot \mathrm{e}^{-x^2 + 2xy - y^2}\mathrm{d}y$ $= \frac{1}{\pi}\mathrm{e}^{-x^2}\int_{-\infty}^{+\infty}\mathrm{e}^{-(y - x)^2}\mathrm{d}y = \frac{1}{\sqrt{\pi}}\mathrm{e}^{-x^2},$于是 $f_{Y|X}(y|x) = \frac{f(x,y)}{f_X(x)} = \frac{\frac{1}{\pi}\mathrm{e}^{-2x^2 + 2xy - y^2}}{\frac{1}{\pi}\mathrm{e}^{-x^2}} = \frac{1}{\sqrt{\pi}}\mathrm{e}^{-x^2 + 2xy - y^2} = \frac{1}{\sqrt{\pi}}\mathrm{e}^{-(y - x)^2}.$
