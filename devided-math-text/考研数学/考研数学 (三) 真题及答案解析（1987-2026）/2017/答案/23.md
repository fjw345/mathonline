【详解】（1）先求 $Z_{i}$ 的分布函数为

$$
F _ {Z} (z) = P \left\{Z _ {i} \leq z \right\} = P \left\{\left| X _ {i} - \mu \right| \leq z \right\} = P \left\{\frac {\left| X _ {i} - \mu \right|}{\sigma} \leq \frac {z}{\sigma} \right\} \Leftrightarrow
$$

当 $z < 0$ 时，显然 $F_{Z}(z) = 0$；

当 $z \geq 0$ 时，$F_{Z}(z) = P\{Z_{i} \leq z\} = P\{|X_{i} - \mu| \leq z\} = P\left\{\frac{|X_{i} - \mu|}{\sigma} \leq \frac{z}{\sigma}\right\} = 2\Phi\left(\frac{z}{\sigma}\right) - 1;$

所以 $Z_{i}$ 的概率密度为 $f_{Z}(z) = F_{Z}^{\prime}(z) = \left\{ \begin{array}{ccc} \frac{2}{\sqrt{2\pi}\sigma} e^{-\frac{z^{2}}{2\sigma^{2}}}, & z \geq 0 \\ 0, & z < 0 \end{array} \right.$.

(2) 数学期望 $EZ_{i}=\int_{0}^{+\infty}zf(z)dz=\int_{0}^{+\infty}\frac{2}{\sqrt{2\pi}\sigma}ze^{-\frac{z^{2}}{2\sigma^{2}}}dz=\frac{2\sigma}{\sqrt{2\pi}}$ ,

令 $EZ = \overline{Z} = \frac{1}{n}\sum_{i=1}^{n}Z_{i}$，解得 $\sigma$ 的矩估计量 $\overline{\sigma} = \frac{\sqrt{2\pi}}{2}\overline{Z} = \frac{\sqrt{2\pi}}{2n}\sum_{i=1}^{n}Z_{i}$.

（3）设 $Z_{1}, Z_{2}, \cdots, Z_{n}$ 的观测值为 $z_{1}, z_{2}, \cdots, z_{n}$. 当 $z_{i} > 0, i = 1, 2, \cdots, n$ 时似然函数为 $L(\sigma) = \prod_{i=1}^{n} f(z_i, \sigma) = \frac{2^n}{(\sqrt{2\pi}\sigma)^n} e^{-\frac{1}{2\sigma^2} \sum_{i=1}^{n} z_i^2},$

取对数得: $\ln L(\sigma) = n\ln 2 - \frac{n}{2}\ln (2\pi) - n\ln \sigma -\frac{1}{2\sigma^2}\sum_{i = 1}^{n}z_i^2 < i$

令 $\frac{d\ln L(\sigma)}{d\sigma} = -\frac{n}{\sigma} +\frac{1}{\sigma^3}\sum_{i = 1}^{n}z_i^2 = 0$ ，得参数 $\sigma$ 最大似然估计量为 $\sigma = \sqrt{\frac{1}{n}\sum_{i = 1}^{n}z_i^2}$ :
