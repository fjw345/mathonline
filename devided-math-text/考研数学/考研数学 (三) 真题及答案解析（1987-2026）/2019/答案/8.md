(8) A

解 由 $X \sim N(\mu, \sigma^2), Y \sim N(\mu, \sigma^2)$，且相互独立，

则 $E(X - Y) = 0, D(X - Y) = DX + DY = 2\sigma^2$，得 $\frac{X - Y}{\sqrt{2}\sigma} \sim N(0,1)$，

故 $P\{|X - Y| < 1\} = P\left\{\frac{|X - Y|}{\sqrt{2}\sigma} < \frac{1}{\sqrt{2}\sigma}\right\} = 2\Phi \left(\frac{1}{\sqrt{2}\sigma}\right) - 1$ 与 $\sigma^2$ 有关，与 $\mu$ 无关. 故应选A.
