【解析】法1:由泰勒公式 $\tan x = x + \frac{1}{3} x^3 + O(x^3)$ 得
$\lim_{x \to 0} \frac{P(x) - \tan x}{x^3} = \lim_{x \to 0} \frac{a + (b - 1)x + cx^2 + (d - \frac{1}{3})x^3 + o(x^3)}{x^3} = 0$

$a = 0, b = 1, c = 0, d = \frac{1}{3}$, 故选（D）.

法2:由条件及

$\lim_{x \to 0} \tan x = 0$, 知 $a = 0$, 又 $\lim_{x \to 0} \frac{P(x) - \tan x}{x^3} = \lim_{x \to 0} \frac{b + 2cx + 3dx^2 - \sec^2 x}{3x^2}, \lim_{x \to 0} \sec^2 x = 0,$

故 $b = 1$, 同理，再用洛比达法则可得 $c = 0, d = \frac{1}{3}$, 故选（D）.

【答案】D
