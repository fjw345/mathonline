【解】$\frac{\partial z}{\partial x} = e^{x}\cos y\cdot f^{\prime},\quad \frac{\partial z}{\partial y} = -e^{x}\sin y\cdot f^{\prime},$
$\frac{\partial^2z}{\partial x^2} = e^x\cos y\cdot f' + e^{2x}\cos^2y\cdot f'',\quad \frac{\partial^2z}{\partial y^2} = -e^x\cos y\cdot f' + e^{2x}\sin^2y\cdot f''.$
$\frac{\partial^2z}{\partial x^2} +\frac{\partial^2z}{\partial y^2} = e^{2xf''},$
令 $u = e^{x}\cos y$ ，由 $\frac{\partial^2z}{\partial x^2} +\frac{\partial^2z}{\partial y^2} = (4z + e^x\cos y)e^{2x}$ 得
$f''(u) = 4f(u) + u$ ，或 $f''(u) - 4f(u) = u$
解得 $f(u) = C_1e^{-2u} + C_2e^{2u} - \frac{1}{4} u$
由 $f(0) = 0,f'(0) = 0$ 得 $\left\{ \begin{array}{l}C_{1} + C_{2} = 0\\ -2C_{1} + 2C_{2} - \frac{1}{4} = 0 \end{array} \right.$ 解得 $C_1 = -\frac{1}{16},C_2 = \frac{1}{16},$
故 $f(u) = -\frac{1}{16}(e^{-2u} - e^{2u}) - \frac{1}{4} u$ 。
