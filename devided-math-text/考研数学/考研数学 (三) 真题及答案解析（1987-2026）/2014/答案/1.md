【解析】 $\because \lim_{x\to \infty}a_n = a$

$\therefore \forall \varepsilon > 0$ $\exists N \in N^{+} s.t \forall n > N$ 时，有 $|a_{n} - a| < \varepsilon$

即 $a - \varepsilon < a_{n} < a + \varepsilon.\Rightarrow ||a| - \varepsilon |\triangleleft a_{n}|\triangleleft a| + \varepsilon$

取 $\varepsilon = \frac{|a|}{3}$. 有 $|a_n| \geq \frac{2|a|}{3} > \frac{|a|}{2}$
