【解析】

(1) $P(T > t) = 1 - P(T\leq t) = e^{-\left(\frac{t}{\theta}\right)^m}$

$P(T > t) = 1 - P(T\leq t) = e^{-\left(\frac{t}{\theta}\right)^m}$

$P(T > s + t|T > s) = \frac{P(T > s + t)}{P(T > s)} = \frac{e^{-\left(\frac{s + t}{\theta}\right)^m}}{e^{-\left(\frac{t}{\theta}\right)^m}}$

（2）由题意可得概率密度函数为 $f(t) = F(t) = \left\{ \begin{array}{l}\frac{mt^{m - 1}}{\theta^m} e^{-\left(\frac{t}{\theta}\right)^m}, t > 0\\ 0,t\leqslant 0 \end{array} \right.$

$f(t) = F^{*}(t) = \left\{ \begin{array}{cc} \frac{mt^{m - 1}}{\theta^{m}}\mathrm{e}^{-\left(\frac{t}{\theta}\right)^{m}}, & t > 0\\ 0, & t\leq 0 \end{array} \right.$

旺旺id 河北师大研胜教育似然函数 $L(\theta) = \frac{m^n\prod_{i=1}^n t_i^{m-1}}{\theta^{mn}} e^{-\sum_{i=1}^n\left(\frac{t_i}{\theta}\right)^m}, t_i > 0, i = 1,2,\dots,n$

取对数有 $\ln L(\theta) = n \ln m + (m-1)\sum_{i=1}^n \ln t_i - mn \ln \theta - \sum_{i=1}^n\left(\frac{t_i}{\theta}\right)^m$

求导并令导数等于零，$\frac{d \ln L(\theta)}{d\theta} = -\frac{mn}{\theta} + \frac{m}{\theta^{m+1}} \sum_{i=1}^n t_i^m = 0$

解得 $\hat{\theta} = \sqrt[\mum]{\frac{1}{n}\sum_{i=1}^n t_i^m}$.
