【解析】 $\lim_{n\to \infty}\left|\frac{\frac{(-4)^{n + 1} + 1}{4^{n + 1}(2n + 3)}x^{2n + 2}}{\frac{(-4)^n + 1}{4^n(2n + 1)}x^{2n}}\right| < 1,$ 解得 $\left|x\right| < 1,\therefore R = 1.$ 收敛区间为 $(-1,1)$ 当 $x = \pm 1$ 时， $\sum_{n = 0}^{\infty}\frac{(-4)^n + 1}{4^n(2n + 1)}$ 收敛，收敛域为[-1,1].$S(x) = \sum_{n = 0}^{\infty}\frac{(-1)^n}{2n + 1} x^{2n} + \sum_{n = 0}^{\infty}\frac{x^{2n}}{4^n(2n + 1)}.$ 设 $S_{1}(x) = \sum_{n = 0}^{\infty}\frac{(-1)^{n}}{2n + 1} x^{2n} = \frac{1}{x}\sum_{n = 0}^{\infty}\frac{(-1)^{n}}{2n + 1} x^{2n + 1},x\neq 0.$
