【答案】(C)
【解析】 $F(x,y) = \int_0^{x - y}(x - y - t)f(t)dt = (x - y)\int_0^{x - y}f(t)dt - \int_0^{x - y}tf(t)dt.$ 则 $\frac{\partial F}{\partial x} = \int_0^{x - y}f(t)dt + (x - y)f(x - y) - (x - y)f(x - y) = \int_0^{x - y}f(t)dt,$ 于是 $\frac{\partial^2F}{\partial x^2} = f(x - y)$
同理， $\frac{\partial F}{\partial y} = -\int_0^{x - y}f(t)dt - (x - y)f(x - y) + (x - y)f(x - y) = -\int_0^{x - y}f(t)dt$ 于是 $\frac{\partial^2F}{\partial y^2} = f(x - y)$
综上所述， $\frac{\partial F}{\partial x} = -\frac{\partial F}{\partial y},\frac{\partial^2F}{\partial x^2} = \frac{\partial^2F}{\partial y^2}$ ，故选(C).
