【答案】(A)
【解析】 $I_{1} = \int_{0}^{1}\frac{\frac{x}{2}}{1 + \cos x} dx,I_{2} = \int_{0}^{1}\frac{\ln(1 + x)}{1 + \cos x} dx,I_{3} = \int_{0}^{1}\frac{x}{\frac{1 + \sin x}{2}} dx.$
令 $f(x) = \frac{x}{2} -\ln (1 + x),x\in (0,1)$ 且 $f(0) = 0$
则 $f^{\prime}(x) = \frac{1}{2} -\frac{1}{1 + x} = \frac{x - 1}{2(1 + x)} < 0$ ，即 $f(x)$ 单调递减，则 $f(x) < f(0) = 0$
即 $\frac{x}{2} < \ln (1 + x),x\in (0,1)$ ，则 $I_{1} < I_{2}$
因 $\ln (1 + x) < x,\frac{1 + \sin x}{2} < 1 + \cos x,x\in (0,1)$ ，于是 $\frac{\ln(1 + x)}{1 + \cos x} < \frac{x}{\frac{1 + \sin x}{2}}\Rightarrow I_3 > I_2.$
