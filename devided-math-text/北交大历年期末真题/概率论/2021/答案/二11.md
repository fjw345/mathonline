解:标准正态分布 $X \sim N(0,1)$，$\varphi(x) = \frac{1}{\sqrt{2\pi}} e^{\frac{-x^2}{2}}$，$\Phi(x) = \int_{-\infty}^{x} \varphi(t) dt$，$\Phi(x) + \Phi(-x) = 1$。因此，有 $P(X \leq a) = P\left(\frac{X - \mu}{\sigma} \leq \frac{a - \mu}{\sigma}\right) = \Phi\left(\frac{a - \mu}{\sigma}\right)$；$P(X \geq a) = 1 - \Phi\left(\frac{a - \mu}{\sigma}\right)$；$P(a \leq X \leq b) = \Phi\left(\frac{b - \mu}{\sigma}\right) - \Phi\left(\frac{a - \mu}{\sigma}\right)$；$P(|X - \mu| \leq a) = \Phi\left(\frac{a}{\sigma}\right) - \Phi\left(-\frac{a}{\sigma}\right) = 2\Phi\left(\frac{a}{\sigma}\right) - 1$；$P(|X - \mu| > a) = 1 - P(|X - \mu| \leq a) = 2\left(1 - \Phi\left(\frac{a}{\sigma}\right)\right)$。
