解:（1）因为 $EX=\int_{-\infty}^{+\infty}xf(x)dx=\int_{0}^{+\infty}x\lambda^{2}xe^{-\lambda x}dx=-\lambda\int_{0}^{+\infty}x^{2}de^{-\lambda x}=-\lambda\left[x^{2}e^{-\lambda x}\right|_{0}^{+\infty}-2\int_{0}^{+\infty}xe^{-\lambda x}dx=\frac{2}{\lambda}$
所以由 $EX = \overline{X}$ ，可得参数 $\lambda$ 的矩估计量为 $\hat{\lambda} = 2 / \overline{X}$

(2) 似然函数为 $L(\lambda) = \prod_{i=1}^{n} \lambda^2 x_i e^{-\lambda x_i} = \lambda^{2n} \prod_{i=1}^{n} x_i e^{-\lambda \sum_{i=1}^{n} x_i}$

取对数，可得 $\ln L(\lambda) = \ln \prod_{i=1}^{n} \lambda^2 x_i e^{-\lambda x_i} = 2n \ln \lambda - \lambda \sum_{i=1}^{n} x_i + \sum_{i=1}^{n} \ln x_i$。

令其关于 $\lambda$ 的导数等于 0，即

$\frac{d}{d\lambda} [\ln L(\lambda)] = \frac{2n}{\lambda} - \sum_{i=1}^{n} x_i = 0$

解得 $\lambda$ 的最大似然估计值为 $\hat{\lambda} = \frac{2n}{\sum_{i=1}^{n} x_i}$，

所以 $\lambda$ 的最大似然估计量为 $\hat{\lambda} = \frac{2}{\bar{X}}$。
