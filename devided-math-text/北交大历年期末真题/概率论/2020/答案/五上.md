解:（1）设 $Z$ 为商店所获利润，

$$
Z = g (X, Y) = \left\{ \begin{array}{c l} 1 0 0 0 Y + 5 0 0 (X - Y), & X \geq Y \\ 1 0 0 0 X, & X < Y \end{array} \right.
$$

$X$ 和 $Y$ 的概率密度函数分别为

$$
f (x) = \left\{ \begin{array}{l l} \frac {1}{1 0}, & 1 0 \leq x \leq 2 0 \\ 0, & \text {其它;} \end{array} , \quad f (y) = \left\{ \begin{array}{l l} \frac {1}{1 0}, & 1 0 \leq y \leq 2 0 \\ 0, & \text {其它;} \end{array} \right. \right.
$$

$X$ 与 $Y$ 相互独立，（ $X,Y$ ）的联合概率密度函数为

$$
f (x, y) = \left\{ \begin{array}{l l} \frac {1}{1 0 0}, & 1 0 \leq x \leq 2 0, 1 0 \leq y \leq 2 0 \\ 0, & \text {其它;} \end{array} \right.
$$

（2）商店所获利润的期望值为

$$
E Z = \int_ {- \infty} ^ {\infty} \int_ {- \infty} ^ {\infty} g (x, y) f (x, y) d x d y
$$
