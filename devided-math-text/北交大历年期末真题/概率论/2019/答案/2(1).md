解:由 $X$ 表示在 $n$ 次独立重复试验中事件 $A$ 发生的次数，所以 $X \sim B(n, p)$。且 $p = P(A) = \frac{1}{2}$。所以，$E(X) = np = \frac{n}{2}$，$D(X) = np(1 - p) = \frac{n}{4}$。但是

$D(X) = E(X^2) - [E(X)]^2 = E(X(X - 1)) + E(X) - [E(X)]^2 = 5 + \frac{n}{2} - \left(\frac{n}{2}\right)^2 = \frac{n}{4}$。

由此，得方程 $\frac{n^2}{4} - \frac{n}{4} - 5 = 0$，即 $n^2 - n - 20 = 0$。

解方程，得 $n_1 = 5$，$n_2 = -4$。舍去 $n_2 = -4$，得 $n_1 = 5$。
