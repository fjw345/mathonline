【解】设 $Y$ 为每件产品的利润，则

$$
Y = \left\{ \begin{array}{l l} c _ {1} & 1 0 \leq X \leq 1 2 \\ - c _ {2} & X < 1 0 \\ - c _ {3} & X > 1 2 \end{array} \right.
$$

因此， $g(\mu) = E(Y) = c_1P\{10\leq X\leq 12\} -c_2P\{X < 10\} -c_3P\{X > 12\}$

$$
\begin{array}{l} = c _ {1} P \left\{\frac {1 0 - \mu}{1} \leq \frac {X - \mu}{1} \leq \frac {1 2 - \mu}{1} \right\} - c _ {2} P \left\{\frac {X - \mu}{1} < \frac {1 0 - \mu}{1} \right\} - c _ {3} P \left\{\frac {X - \mu}{1} > \frac {1 2 - \mu}{1} \right\} \\ = c _ {1} \left(\Phi \left(\frac {1 2 - \mu}{1}\right) - \Phi \left(\frac {1 0 - \mu}{1}\right)\right) - c _ {2} \Phi \left(\frac {1 0 - \mu}{1}\right) - c _ {3} \left(1 - \Phi \left(\frac {1 2 - \mu}{1}\right)\right) \\ = c _ {1} (\Phi (1 2 - \mu) - \Phi (1 0 - \mu)) - c _ {2} \Phi (1 0 - \mu) - c _ {3} (1 - \Phi (1 2 - \mu)) \\ = (c _ {1} + c _ {3}) \Phi (1 2 - \mu) - (c _ {1} + c _ {2}) \Phi (1 0 - \mu) - c _ {3}. \end{array}
$$

所以， $g^{\prime}(\mu) = -(c_{1} + c_{3})\Phi^{\prime}(12 - \mu) + (c_{1} + c_{2})\Phi^{\prime}(10 - \mu)$
