【解】记 $p_{ij} = P(X_1 = i, X_2 = j)$，$p_{i.} = P(X_1 = i)$，$p_{.j} = P(X_2 = j)$，$(i,j = 0, 1, 2)$。由 $P(X_1X_2 = 0) = 1$，得 $P(X_1X_2 \neq 0) = p_{11} + p_{12} + p_{21} + p_{22} = 0$。所以，$p_{11} + p_{12} + p_{21} + p_{22} = 0$。所以，$p_{11} = p_{12} = p_{21} = p_{22} = 0$（非负性）。又 $p_{1.} = P\{X_1 = 1\} = p_{10} + p_{11} + p_{12} = p_{10} + 0 + 0 = p_{10}$，所以，$p_{10} = p_{1.} = \frac{1}{4}$。$p_{2.} = P\{X_2 = 1\} = p_{20} + p_{21} + p_{22} = p_{20} + 0 + 0 = p_{20}$，所以，$p_{20} = p_{2.} = \frac{1}{4}$。所以，$p_{00} = p_{0} - p_{10} - p_{20} = \frac{1}{2} - \frac{1}{4} - \frac{1}{4} = 0$。
