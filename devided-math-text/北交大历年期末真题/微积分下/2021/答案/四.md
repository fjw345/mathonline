解:设矩形的长、宽分别为 $2x, 2y$.则矩形面积 $A = 4xy$，且 $x^{2} + 4y^{2} = 16$.令 $L = 4xy + \lambda (x^{2} + 4y^{2} - 16)$ 4分由 $\begin{cases} L_{x} = 4y + 2\lambda x = 0 \\ L_{y} = 4x + 8\lambda y = 0 \\ L_{\lambda} = x^{2} + 4y^{2} - 16 = 0 \end{cases}$ 得驻点 $x = 2\sqrt{2}, y = \sqrt{2}$.8分由于实际问题必定存在最大值.因此当矩形的长、宽分别取 $2\sqrt{2}, \sqrt{2}$ 时，有最大面积16.10分
