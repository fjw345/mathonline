(1) $\frac{\partial P}{\partial y} = e^{x} + \cos y, \frac{\partial Q}{\partial x} = e^{x} + \cos y.$ $\because \frac{\partial P}{y} = \frac{\partial Q}{\partial x}, \therefore$ 存在 $\mu(x, y)$, 使 $du = Pdx + Qdy.$ (2) $u(x, y) = \int_{(x_0, y_0)}^{(x, y)} Pdx + Qdy$ $= \int_{x_0}^{x} (y_0e^x + \sin y_0)dx + \int_{y_0}^{y} (e^x + x\cos y)dy$ $= [y_0e^x + x\sin y_0]_{x_0}^x + [ye^x + x\sin y]_{y_0}^y$ $= ye^x + x\sin y + C$ 其中 $C$ 为任意常数.
