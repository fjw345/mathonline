解:抛物线 $y = x^2$ 上点 $(x, y)$ 到点(3,0)的距离平方 $d^2 = (x - 3)^2 + y^2$.

令 $F = (x - 3)^2 + y^2 + \lambda(y - x^2)$ 4分由 $\begin{cases} F_x = 2(x - 3) - 2\lambda x = 0 \\ F_y = 2y + \lambda = 0 \\ F_\lambda = y - x^2 = 0 \end{cases}$ 得唯一驻点(1,1) 8分因最小值必定存在，故 $d_{\min} = d(1,1) = \sqrt{5}$.

所以，点(3,0)到抛物线 $y = x^2$ 的距离为 $\sqrt{5}$. 10分
