解: $R = \lim_{n\to \infty}\left|\frac{a_n}{a_{n + 1}}\right| = \lim_{n\to \infty}\frac{(n^2 + 1)2^{n + 1}(n + 1)!}{2^n\cdot n![(n + 1)^2 + 1]} = +\infty$ ，故收敛域为 $\left(-\infty, +\infty\right)$ 。$\sum_{n = 0}^{\infty}\frac{n^2 + 1}{2^n\cdot n!} x^n = \sum_{n = 0}^{\infty}\frac{1}{n!}\left(\frac{x}{2}\right)^n + \sum_{n = 1}^{\infty}\frac{n}{(n - 1)!}\left(\frac{x}{2}\right)^n = e^{\frac{x}{2}} + x\sum_{n = 1}^{\infty}\frac{n}{(n - 1)!}\cdot \frac{x^{n - 1}}{2^n}.$ 令 $\sum_{n = 1}^{\infty}\frac{n}{(n - 1)!2^n} x^{n - 1} = S(x)$ ，则 $\int_0^x S(x)dx = \sum_{n = 1}^{\infty}\frac{x^n}{(n - 1)!2^n} = \frac{x}{2}e^{\frac{x}{2}},$ $S(x) = (\frac{x}{2}e^{\frac{y}{2}})' = \frac{1}{2}(e^{\frac{y}{2}} + \frac{x}{2}e^{\frac{y}{2}}) = \frac{1}{2}(1 + \frac{x}{2})e^{\frac{y}{2}},$ 所以， $\sum_{n = 0}^{\infty}\frac{n^2 + 1}{2^n\cdot n!} x^n = e^{\frac{y}{2}}(1 + \frac{x}{2} +\frac{x^2}{4}), x\in (-\infty , + \infty)$ 另解: $R = \lim_{n\to \infty}\left|\frac{a_n}{a_{n + 1}}\right| = \lim_{n\to \infty}\frac{(n^2 + 1)2^{n + 1}(n + 1)!}{2^n\cdot n![(n + 1)^2 + 1]} = +\infty$ ，故收敛域为 $\left(-\infty , + \infty\right)$ 。$\sum_{n = 0}^{\infty}\frac{1 + n^2}{n!}\left(\frac{x}{2}\right)^n t = \frac{x}{2}\sum_{n = 0}^{\infty}\frac{1 + n^2}{n!} t^n$ 令 $S(t) = \sum_{n = 0}^{\infty}\frac{1 + n^2}{n!} t^n = \sum_{n = 0}^{\infty}\frac{t^n}{n!} +\sum_{n = 1}^{\infty}\frac{n^2}{n!} t^n$ $= e^{t} + \sum_{n = 1}^{\infty}\frac{n}{(n - 1)!} t^n = e^{t} + \sum_{n = 1}^{\infty}\frac{n - 1 + 1}{(n - 1)!} t^n$ $= e^{t} + \sum_{n = 1}^{\infty}\frac{t^n}{(n - 1)!} +\sum_{n = 2}^{\infty}\frac{1}{(n - 2)!} t^n$ $= e^{t} + te^{t} + t^{2}e^{t}.$ 故 $S(x) = e^{\frac{x}{2}}\left(1 + \frac{x}{2} +\frac{x^2}{4}\right), x\in (-\infty , + \infty)$
