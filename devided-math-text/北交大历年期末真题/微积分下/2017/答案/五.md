解: $M = \iint_{S}\mu (x,y,z)dS = 9\iint_{S}\sqrt{x^2 + y^2 + z^2}dS$ 注意到 $S$ 的投影区域为 $D:x^{2} + y^{2}\leq 2x$ ，$\frac{\partial z}{\partial x} = \frac{x}{\sqrt{x^2 + y^2}},\frac{\partial z}{\partial y} = \frac{y}{\sqrt{x^2 + y^2}}$ 于是 $M = 18\iint_{D}\sqrt{x^2 + y^2}dxdy = 18\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}}d\theta \int_0^{2\cos \theta}r\cdot rdr = 48\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}}\cos^3\theta d\theta = 64.$
