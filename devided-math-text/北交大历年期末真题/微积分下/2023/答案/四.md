解:设 $d^2 = x^2 + y^2 + (z - 1)^2$，以及 $\varphi(x, y, z) = xy - z = 0$，
令 $L(x, y, z, \lambda) = d^2 + \lambda\varphi = x^2 + y^2 + (z - 1)^2 + \lambda\varphi(x, y, z)$.
则由 $\begin{cases} L_x = L_y = L_z = 0 \\ L_\lambda = xy - z = 0 \end{cases}$，得 $x = y = z = 0$。
由实际问题，因此

$$
d = d _ {\min} = d (0, 0, 0) = \sqrt {0 ^ {2} + 0 ^ {2} + (0 - 1) ^ {2}} = 1.
$$
