解:由 $f'(x) = \frac{1}{1 + x^2} = \sum_{n=0}^{\infty} (-1)^n x^{2n}, \quad x \in (-1, 1)$ …3分所以，$f(x) = \int_0^x \frac{1}{1 + x^2} dx = \sum_{n=0}^{\infty} (-1)^n \frac{x^{2n+1}}{2n+1}, \quad x \in [-1, 1]$. …6分再 $\sum_{n=1}^{\infty} \frac{(-1)^n}{2n-1} \left( \frac{3}{4} \right)^n = \sum_{n=0}^{\infty} \frac{(-1)^{n+1}}{2n+1} \left( \frac{3}{4} \right)^{n+1}$

$= -\frac{\sqrt{3}}{2} \sum_{n=0}^{\infty} \frac{(-1)^n}{2n+1} \left( \frac{\sqrt{3}}{2} \right)^{2n+1} = -\frac{\sqrt{3}}{2} \arctan \left( \frac{\sqrt{3}}{2} \right)$. …10分注:很多人，愿意写成 $f(x) = \sum_{n=1}^{\infty} (-1)^{n-1} \frac{x^{2n-1}}{2n-1}, \quad x \in [-1, 1]$.

端点的敛散性，易知当 $x = -1$ 时，$\sum_{n=0}^{\infty} (-1)^n \frac{x^{2n+1}}{2n+1} = \sum_{n=0}^{\infty} (-1)^{n+1} \frac{1}{2n+1}$，条件收敛；

当 $x = 1$ 时，$\sum_{n=0}^{\infty} (-1)^n \frac{x^{2n+1}}{2n+1} = \sum_{n=0}^{\infty} (-1)^n \frac{1}{2n+1}$，条件收敛.
