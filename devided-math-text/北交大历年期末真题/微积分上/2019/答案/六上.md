解:由题意，知 $ax + b$ 与 $\ln x$ 相切于[2，4]内的点 $x = x_0$ ，则有

$\left\{ \begin{array}{l} ax_{0} + b = \ln x_{0}, \\ a = \frac{1}{x_{0}}, \end{array} \right. \Rightarrow a = \frac{1}{e^{b+1}}$

因此，$I = \int_{2}^{4} (ax + b - \ln x) dx = 6a + 2b - \int_{2}^{4} \ln x dx = \frac{6}{e^{b+1}} + 2b - 6 \ln 2 + 2$.

令 $\frac{dI}{db} = 0$，得 $b = \ln 3 - 1$，进而 $a = \frac{1}{3}$.——唯一驻点
