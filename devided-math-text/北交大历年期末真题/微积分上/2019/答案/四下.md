解:当 $-\pi < x < 0$ 时，$\left\{ \begin{array}{l}yy' + x = 0,\\ y(-\frac{\pi}{\sqrt{2}}) = \frac{\pi}{\sqrt{2}}.\end{array} \right.\Rightarrow y = \sqrt{\pi^2 - x^2};$

当 $0\leq x < \pi$ 时，$\left\{ \begin{array}{l}y'' + y = -x,\\ y(0) = \pi ,y'(0) = 0.\end{array} \right.\Rightarrow y = \pi \cos x + \sin x - x,$

所以，$y = y(x) = \left\{ \begin{array}{ll}\sqrt{\pi^2 - x^2}, & -\pi < x < 0,\\ \pi \cos x + \sin x - x, & 0\leq x < \pi . \end{array} \right.$
