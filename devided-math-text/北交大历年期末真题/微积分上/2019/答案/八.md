解:当 $-1\leq x < 0$ 时， $F(x) = \int_{-1}^{x}f(t)dt = \int_{-1}^{x}(2t + \frac{3}{2} t^2)dt = x^2 +\frac{1}{2} x^3 -\frac{1}{2};$

当 $0 \leq x \leq 1$ 时，$F(x) = \int_{-1}^{x} f(t) dt = \int_{-1}^{0} f(t) dt + \int_{0}^{x} f(t) dt$

$= \int_{-1}^{0} (2t + \frac{3}{2} t^2) dt + \int_{0}^{x} \frac{te^t}{(e^t + 1)^2} dt$

$= -\frac{1}{2} - \int_{0}^{x} td \frac{1}{e^t + 1} = -\frac{1}{2} - \frac{x}{e^x + 1} + \int_{0}^{x} \frac{1}{e^t + 1} dt$

$= -\frac{1}{2} - \frac{x}{e^x + 1} + x - \ln(e^x + 1) + \ln 2.$

所以，$F(x) = \begin{cases} x^2 + \frac{1}{2} x^3 - \frac{1}{2}, & -1 \leq x < 0, \\ x - \ln(e^x + 1) - \frac{x}{e^x + 1} + \ln 2 - \frac{1}{2}, & 0 \leq x < 1. \end{cases}$
