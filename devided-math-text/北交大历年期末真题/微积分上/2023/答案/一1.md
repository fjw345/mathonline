解:

$$
\lim _ {x \to 1} \frac {a x + b}{\sqrt {3 x + 1} - \sqrt {x + 3}} = \lim _ {x \to 1} \frac {(a x + b) (\sqrt {3 x + 1} + \sqrt {x + 3})}{(3 x + 1) - (x + 3)}
$$

$$
= \lim _ {x \to 1} \frac {4 \cdot (a x + b)}{2 (x - 1)} = \lim _ {x \to 1} \frac {2 a x + 2 b}{(x - 1)} = 4.
$$

所以， $a = 2, b = -2$

故选（A）.
