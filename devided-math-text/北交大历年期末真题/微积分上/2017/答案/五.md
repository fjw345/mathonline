解:对积分 $\int_{0}^{x}f(x - t)dt$ 进行换元，设 $x - t = u$ ，则 $dt = -du$ ，故$\int_{0}^{x}f(x - t)dt = \int_{x}^{0}f(u)(-du) = \int_{0}^{x}f(u)du$ 2分故方程变为$f(x) = \sin x - \int_{0}^{x}f(u)du$ 两边求导得$f'(x) = \cos x - f(x)$ 注意到 $f(0) = 0$ 归结为求解初值问题 $\left\{ \begin{array}{l}f'(x) + f(x) = \cos x\\ f(0) = 0 \end{array} \right.$ 4分$f(x) = e^{-\int_{1d}dx}\left[\int \cos xe^{\int_{1d}dx}dx + C\right] = e^{-x}\left[\int \cos xe^xdx + C\right]\\ = e^{-x}\left[\frac{1}{2} (\cos x + \sin x)e^x +C\right]$ 6分代入初值 $f(0) = 0$ 求得常数 $C = -\frac{1}{2}$ 故所求函数为$f(x) = \frac{1}{2} (\cos x + \sin x - e^{-x})$ 8分
