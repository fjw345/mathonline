(3) 由于 $\lim_{x\to 0 + }f(x) = \lim_{x\to 0 + }xe^{\frac{1}{x}} = \lim_{t\to +\infty}\frac{e^t}{t} = +\infty$ ，所以 $x = 0$ 是垂直渐近线；又由于 $\lim_{x\to \infty}\frac{f(x)}{x} = \lim_{x\to \infty}\frac{xe^{\frac{1}{x}}}{x} = 1,$ $\lim_{x\to \infty}(f(x) - x) = \lim_{x\to \infty}\left(xe^{\frac{1}{x}} - x\right) = \lim_{x\to \infty}\left(\frac{e^{\frac{1}{x}} - 1}{\frac{1}{x}}\right) = 1,$

所以，函数图形的斜渐近线为 $y = x + 1$
