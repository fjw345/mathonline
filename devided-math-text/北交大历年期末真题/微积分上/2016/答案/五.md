解:对积分 $\int_{0}^{x} f(t - x) dt$ 进行换元，设 $t - x = -u$，则 $dt = -du$，
故 $\int_{0}^{x} f(t - x) dt = \int_{x}^{0} f(-u)(-du) = \int_{0}^{x} f(-u) du = \int_{0}^{x} -f(u) du$，2分故方程变为 $f'(x) + \int_{0}^{x} f(u) du = 2$ 4分注意到 $f(x)$ 是奇函数，故 $f(0) = 0$；由上式得 $f'(0) = 2$，
归结为求解初值问题 $\begin{cases} f''(x) + f(x) = 0 \\ f(0) = 0 \\ f'(0) = 2 \end{cases}$ 6分特征方程为 $r^2 + 1 = 0, r = \pm i$，于是通解为
$f(x) = C_1 \cos x + C_2 \sin x$
代入初值求得常数 $C_1 = 0, C_2 = 2$ 故所求函数为 $f(x) = 2 \sin x$ 8分
