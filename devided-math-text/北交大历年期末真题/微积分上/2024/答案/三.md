解:由已知， $f(x)$ 在 $x = 0$ 处连续，故由

$f(0 - 0) = 0,\quad f(0) = 0,\quad f(0 + 0) = 1 + b$ ，知 $b = -1$ 再由 $f(x)$ 在 $x = 0$ 处可导，以及

$$
f _ {-} ^ {\prime} (0) = \lim _ {x \to 0 -} \frac {f (x) - f (0)}{x} = \lim _ {x \to 0 -} \frac {\sin a x - 0}{x} = a;
$$

$f_{+}^{\prime}(0) = \lim_{x\to 0 + } \frac{f(x) - f(0)}{x} = \lim_{x\to 0 + }\frac{e^{2x} - 1 - 0}{x} = 2$ ，知 $a = 2$ 综上所述， $a = 2$ ， $b = -1$
