解:设 $F(x) = x^{5} - 5x + k$ ，则 $F^{\prime}(x) = 5(x^{4} - 1) = 5(1 - 1)(x + 1)(x^{2} + 1)$

于是， $x < -1, F'(x) > 0; -1 < x < 1, F'(x) < 0; x > 1, F'(x) > 0$

又 $\lim_{x\to +\infty}F(x) = +\infty$ ， $\lim_{x\to -\infty}F(x) = -\infty$

结合单调性知， $F(-1)>0,F(1)<0$ 才能有三个根.

即 $F(-1) = 4 + k > 0, F(1) = -4 + k < 0$。因此，有 $-4 < k < 4$。
