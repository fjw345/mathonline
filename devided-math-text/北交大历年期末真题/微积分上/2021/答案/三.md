解:由已知，有 $\lim_{x\to 0}\frac{e^x - (ax^2 +bx + 1)}{x^2} = 0$ :$\lim_{x\to 0}\frac{e^x - (2ax + b)}{2x} = 0\Rightarrow \lim_{x\to 0}[e^{x} - (2ax + b)] = 0\Rightarrow b = 1;$ $\lim_{x\to 0}\frac{e^x - 2a}{2} = 0\Rightarrow \lim_{x\to 0}(e^x -2a) = 0\Rightarrow a = \frac{1}{2}.$ ∴ $a = \frac{1}{2},b = 1.$
