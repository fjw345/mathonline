解: $\int_{e}^{+\infty}\frac{\ln xdx}{x} = \int_{e}^{+\infty}(\ln x)d\ln x = \frac{1}{2}\left[(\ln x)^{2}\right]_{e}^{+\infty} = +\infty -\frac{1}{2} = +\infty ;$ $\int_{e}^{+\infty}\frac{dx}{x\ln x} = \int_{e}^{+\infty}\frac{d\ln x}{\ln x} = \left[\ln (\ln x)\right]_{e}^{+\infty} = +\infty ;$ $\int_{e}^{+\infty}\frac{dx}{x\sqrt{\ln x}} = \int_{e}^{+\infty}\frac{d\ln x}{\sqrt{\ln x}} = \left[2\sqrt{\ln x}\right]_{e}^{+\infty} = +\infty ;$ $\int_{e}^{+\infty}\frac{dx}{x(\ln x)^{2}} = \int_{e}^{+\infty}\frac{d\ln x}{(\ln x)^{2}} = \left[-\frac{1}{\ln x}\right]_{e}^{+\infty} = 1.$
