（2）当 $a = -1, b = -2$ 时，方程组增广矩阵化为

$$
\left(\begin{array}{c c c c}a&1&1&b\\1&a&a&2\\1&1&a&1\end{array}\right)\rightarrow \left(\begin{array}{c c c c}1&0&- 1&\frac {3}{2}\\0&1&0&\frac {- 1}{2}\\0&0&0&0\end{array}\right)
$$

特解 $\eta_0 = \frac{1}{2}\begin{pmatrix} 3 \\ -1 \\ 0 \end{pmatrix}$，导出组的基础解系 $\eta = \begin{pmatrix} 1 \\ 0 \\ 1 \end{pmatrix}$. 一般解是 $\eta_0 + k\eta$ ($k$ 任取).
